# 千川文案统一尺度

2026-11-05用户补充：旧版也必须保留，分为“过审版”和“风险版”，可分别调用，不相互覆盖。

## 先选择版本

- 用户说“过审版／保守版／审核版”：使用下文的过审尺度。“过审版”是工作模式名称，不是平台通过保证。
- 用户说“风险版／旧版／原版尺度”：完整读取[风险版路由与旧规则](references/risk-version.md)，再读取所用流程的旧快照。不得自动用下文过审尺度替换其开头、正文、CTA或选材要求；已识别的风险单独报告，不默默改稿。
- 用户明确要求两版：分别产出与命名，保留对照，不相互覆盖。不明确时沿用本批已明确选择的版本；新批无版本信息默认过审版，并在进度中说明，不额外把两版都生成。
- 冻结并在文稿、交接清单、配音和草稿记录`文案模式：过审版/风险版`，另记实际CTA编号、文本路径与哈希；不能只写“CTA1”而混用不同文本。原配音只能匹配同一文本，不能拿风险版音频配过审版字幕。
- 本节版本路由优先于其他入口的“统一尺度”摘要；下面各节仅是过审版要求。两个版本都不授权捏造事实、伪造审核结论、规避平台规则或自动投放。

## 过审版适用范围

选择过审版时，本页优先于旧规则中无条件保留结果承诺、照搬旧固定CTA或豁免开头审核的条款；各流程的篇幅、主题、账号、结构、模型会话、字幕和剪辑参数不因此改变。风险版按独立快照执行，不删除、覆盖旧规则。

## 先保留原钩子，再做词级窄修

- 热门文案的开头就是本次文案的开头，不另造一个温和钩子，不只留第一句。先锁定完整口播开头范围，标题、账号和点赞引流不算钩子。
- 能保留的逐字保留；有露骨表达、确定性效果保证或明确事实问题时，只替换必要的词或短词组。保留原句式、语序、段落、数字清单、欲望入口、反差和力度，不改成另一套建议、劝告或价值立场。
- 用户已授权上述最小替换，但没有授权整句重写、换钩子、删整个开头或重排。若只改词仍无法消除原句的保证含义，列出原句、残留问题及最小修改候选，请用户决定；标记待确认，不能冒充可直接投放稿或继续把该句送入TTS。
- 保存源开头、采用开头及逐项`原词→新词→原因`。差异必须能逐处解释；“同一个意思”不等于保留原钩子。缩短正文也不扩大改开头权限。
- 数量清单是内容交付要求，不等于效果保证；如原来承诺四个方法，仍兑现四项。用户明确要求超短版数量合并时，才沿用该流程既有例外，并记录数字调整。

## 留力度，不保证对方或学习者的结果

- 保留强判断、短句、反差、具体场景、方法和可辨认的收获。力度落在内容与判断，不落在保证吸引、倒追、确定关系、挽回成功、胜过所有人等结果上。
- 正文、开头、过桥、CTA、标题、字幕和画中文字都不能明示或暗示课程必然奏效。重点复核“任何人／每次都／一定／轻松就能／彻底解决／随时”等与效果组合的语义，以及“四分钟产生好感／一个月挑对象／第二次吸引、第三次确立关系／学三分之一便游刃有余”等时间、次数或比例搭配结果的承诺。
- 不仅删掉“轻松”“迅速”或加“可能”就宣称修复；整句仍在保证效果时须继续标记。免责声明、否定句或换成同音词不能抵消实际承诺，也不以规避审核为目标。
- 不新增情绪控制、征服、强迫服从、性暗示或物化描述来补力度。普通“吸引、兴趣、男女相处”等词不设一刀切黑名单，结合整句、课程实际内容和画面判断。
- 优先贴合原句选用“拆解、讲透、识别、表达、建立、直面”等有动作感的词，不强行套同一组狠词；用户不喜欢“研究”作为这套千川CTA的替换词，不用它填补力度。
- 不捏造学员反馈、成绩、科学效应或成功案例。旧学员结果段不能仅换名字变成事实；无法词级修复的结果故事，标记待确认，不擅自用新故事顶替。

## CTA版本门槛

- CTA1、CTA2、CTA1B、CTA2B同样适用新尺度。保留各自原框架和原有删减关系，只做必要词组调整；不是把四版重写成同一个“痛点＋劝告”模板。
- 介绍真实课程内容、具体场景和实际服务，不承诺购买后、学习后必然获得某种关系结果。187节、板块数量、一对一服务和资质只能按实际核实信息使用，不能为增加收获感补造卖点。
- “课程配有一对一分析”不等于保证解决问题。按真实服务范围说明分析与调整思路，不承诺改变他人意愿；不将实际情感服务改名包装为另一种产品。
- 固定只表示所选正式版本的文本、配音、字幕须一致，不表示历史版本免复核。先核对当前确认版本及完整文本，旧版若仍含被拒承诺，不能因为“固定CTA不可改”而自动复用旧音频；先形成词级改动候选并确认，再重配受影响音频、对齐字幕。
- 单条测试稿得到认可，不自动等于四套CTA及其音频、字幕、剪映个人预设都已更新。没有明确替换确认，不覆盖旧版或更改默认版本指针。

## 文案与画面一起检查

- 所有千川形式的开头、正文、CTA背景、画中画、图片及品牌包装都执行保守筛选。街拍不是整体禁用，AI也不免检。
- 优先正常日常着装、公共场景、自然行动与正常距离交流。排除浴袍、明显低胸露胸露背、刻意突出胸臀腹部的构图、身体局部扫拍、亲密暗示与挑逗摆姿。普通裙装、露肩或自然侧身不自动等于违规；看实际使用区间及它与文案组合后的整体氛围，拿不准就不选。
- 固定开头库与固定预设不豁免。旧模板的亲密剪影、露骨口号、结果保证或进群私信等额外内容也要单独检查，不把“不教情感操控”之类否定声明当作合规证明。
- 保留原模式的画幅、字体、音量和转场等制作规则；不能拿一次测试的15.5秒长镜头或跳过开头库的授权，改成所有后续批次的默认值。库不足时报告具体缺口，不擅自换库、延长或跳过原固定资源约束。

## 交接与验收

1. 写作前冻结完整原开头、原文、任务类型、CTA模式和账号；送模型时把本标准的有关限制写入本次千川任务提示，不只生成后扫词。非千川的原长稿、历史会话和固定旧提示词原件不覆盖。
2. 本地逐句复核开头与正文，按实际语义而不是单词黑名单判断；词级变更可追溯，未解决的保证、露骨或事实问题列在稿外。
3. 配音前冻结确认文本与CTA版本；配音、字幕、标题和包装文字逐项一致。词变了，不能继续用仍读出旧承诺的音频。
4. 保持各流程原有时长验收；千川完整实际音频含CTA不超过298秒。文本审核完成不等于TTS、播放、导出或平台通过。
