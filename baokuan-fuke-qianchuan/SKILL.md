# 爆款复刻接千川

把一条不超过 15 秒、带原生男女对白的剧情开头，接成可检查的千川短版剪映草稿。默认链路：

```text
复刻提示词 -> 剧情视频 -> 剧情承接转场 -> 转场 TTS
-> 同女主转场视频 -> 固定 CTA + 少量同女主图片 -> 字幕/预设包装 -> 剪映草稿
```

## 输入契约

每条任务先建立 `handoff.json`。字段和示例见 [references/handoff-schema.md](references/handoff-schema.md)。制稿前至少要确认：

- 原始复刻提示词、对白和剧情逻辑落点；
- 已生成剧情视频的绝对路径；
- 稳定的三位女主编号和对应素材目录；
- 固定 CTA 音频；
- 与该音频一一对应、已经验收的固定 CTA SRT；
- 目标草稿名称。

缺字段时可继续完成前置阶段，但不得假装已经打通后续阶段。用 `scripts/validate_handoff.py` 检查当前状态。视频尚未生成时，可沿用“爆款复刻”任务当前的视频生成方式；付费生成仍须遵守对应视频技能的费用确认规则。

## 生产流程

### 1. 锁定剧情产物

- 提示词是剧情事实来源，不能为了方便接 CTA 而改写角色对白、动作或结尾。
- 检查生成视频是否完整表现提示词的起因、推进、反转和女主结尾反应；不合格的视频不能直接进入剪辑。
- 记录视频真实时长、分辨率、音轨和女主编号。女主编号来自生成首帧/参考图所属的素材目录，不能凭脸猜编号。
- 把剧情视频的原生对白音频抽成独立音频。剪映中的剧情视频轨仍设为静音，以便统一控制声音。

### 2. 写剧情承接转场

调用 `juqing-kaitou-qianchuan-zhuanchang`：

- 输入完整提示词、对白、女主可见反馈、关系阶段和固定 CTA 的承诺范围；
- 先检索 Gary 知识库，只选一个真正匹配剧情因果的机制；
- 只写剧情与 CTA 之间的旁白，不改剧情，不重写 CTA；
- 默认 18–25 秒，优先 20–23 秒；正文只保留可直接配音的内容；
- 保存 `transition.txt`，另存知识依据和字数/预计时长到清单，不把知识卡编号念进音频。

### 3. 生成转场配音

调用 `xiangongyun-tts`，默认 `浩威青叔4.0.pt`、速度 `1.0`：

- 使用短文本模式生成 WAV；
- 按 `-30 dB / 0.3 秒`规则去除异常静音；
- 技术检查后读取真实音频时长；超过 25 秒时，压缩转场文案并只重生成转场，不加速音频；
- 默认不把固定 CTA 合进转场 WAV，二者必须保留为独立音频段。

### 4. 补齐同一女主画面

- 补充素材只能来自 `female_lead_folder`，并用三位编号复核；一条成片内不得混入其他女主。
- 承接转场段必须使用同女主视频，不能用图片、冻结帧或剧情视频尾帧代替。只选无 `错误版`、画面安全且与转场语义相容的视频；浴袍、床景、暴露、低机位身体强调、亲密身体接触、跳切和明显生成幻觉全部排除。
- 转场视频切点落在字幕边界或真实静音处。默认用 3 条同女主视频覆盖 18–25 秒承接段；按语义分成少量完整镜头，不再每 3–5 秒高频切换。同一条源视频可选择不同连续区间，但不能机械重复相同开头。
- 固定 CTA 段改用少量同女主安全图片低频轮换。默认挑选 3–5 张构图不同、内容清楚的图片，按 CTA 的主要语义段落切换；不沿用转场段每 3–5 秒持续换图的节奏，也不为了增加变化反复加入一大批图片。
- CTA 默认选 4 张同女主图片，按 CTA 四个主要语义段低频轮换；音频长度明显变化时可在 3–5 张内调整。同一张图片允许在相隔较远的 CTA 段落再次出现，但不得连续重复。
- 所有相邻画面连接点统一使用剪映原生 `泡泡模糊`，时长 `1.0 秒`，包括剧情视频到承接视频、承接视频之间、视频到 CTA 图片以及 CTA 图片之间。除非用户再次校正，不再使用叠化。
- 同女主转场视频不足以覆盖转场 TTS 时停止制稿并报告缺口；不得偷偷换女主、改用图片顶替转场视频、拉长冻结尾帧或使用审核风险素材补时长。

### 5. 组装剪映草稿

时间线固定为三段：

```text
A 剧情开头：生成视频 + 抽出的原生对白音频
B 承接转场：同女主补充视频 + 转场 TTS
C 固定 CTA：少量同女主图片轮换 + 固定 CTA 音频 + CTA 重点素材
```

结构规则：

- 主视频轨保持空置；剧情视频、同女主补充视频、品牌图层和 CTA 重点素材全部放附加轨 `flag: 2`。
- CTA 区间单独保留一条“竖版 CTA 固定素材”画中画轨。剪映当前把它识别为独立贴纸/画中画层；只放 1 段并覆盖完整 CTA 区间。固定参数为缩放 `43%`、X `795`、Y `774`、旋转 `0°`。该层不属于中段同女主转场素材，也不参与女主素材筛选。
- QA 时将普通画面附加轨、竖版 CTA 固定画中画轨和品牌图层分开核对，不能把画中画 CTA 素材误计入转场视频数量或女主补充素材数量。
- 画面附加轨必须使用轨道级静音；剧情视频片段自身也设为 `-∞ dB`。声音只来自独立的剧情原声、转场 TTS、固定 CTA 和背景音乐轨。
- 音频固定为：剧情原声 `+11.6 dB`、转场 TTS `+10.0 dB`、固定 CTA `+10.0 dB`、`我的预设7` 背景音乐 `0.0 dB`；三段口播淡入、淡出均为 `0.0 秒`。固定 CTA 不改文案、不裁切、不变速。
- 字幕覆盖剧情对白、转场和固定 CTA；以提示词/转场正文/固定 CTA 文本为权威文本，ASR 只供时间。剪映界面固定为研宋体 `9 号`、白色、水平居中、字间距 `0`、行间距 `0`、缩放 `100%`、描边关闭。阴影开启：黑色、不透明度 `90%`、模糊度 `15%`、距离 `5`、角度 `-45°`。位置固定为剪映 X `0`、Y `-819`；后台兼容落点仍记录归一化 `x=0, y=-0.48`，但前台验收必须以 X `0`、Y `-819` 为准。剧情对白、承接转场和固定 CTA 三段必须完全一致。
- 继承当前验收过的千川预设：全程黑曜（用户也称“耀黑”）强度 `50%`，全程暗角边缘暗度 `100`，以及 `我的预设7` 背景音乐。预设层必须适配实际总时长，不能只复制旧时长。
- CTA 包装仅从 CTA 起点出现并覆盖到片尾：免责声明使用系统字体 14 号、白色、缩放 23%、X 0、Y 1891；三行品牌文案使用铂金黑 15 号、白色、缩放 105%、X 0、Y 1206；`五合一187节完整版` 使用铂金黑 14 号、白色、缩放 66%、X 171、Y 768，并开启黑色描边（不透明度 100%、粗细 40）。三层旋转均为 0°，不得提前进入剧情或承接段。
- 总时间线为三段音频的真实总时长，画面不能有空隙、黑帧、尾帧停顿或离线素材。

## 批量与恢复

- 每条任务独立目录，至少保存 `handoff.json`、`transition.txt`、转场 WAV、素材选择清单、草稿路径和 QA 报告。素材清单必须记录每段的源起点、使用时长和对应 `transition`/`cta` 区段，不能只列文件名。
- 批量任务使用 `batch_manifest.jsonl`，按阶段记录 `prompt_ready`、`video_ready`、`transition_ready`、`tts_ready`、`assets_ready`、`draft_written`、`verified`；中断后从最后一个真实完成阶段恢复。
- 不把“提示词已写”“视频已提交”“草稿已落盘”混称为完成。只有所需文件真实存在并通过本地检查后，才能推进下一状态。

## 完成检查

- 剧情视频内容与提示词一致，原生对白音频完整。
- 转场第一秒能听出承接刚才剧情，只解释一个因果机制，真实 TTS 不超过 25 秒。
- 剧情、转场、CTA 三段连续；固定 CTA 原文和音频未改。
- 承接转场全部使用同女主视频；固定 CTA 只使用少量同女主图片低频轮换。视频区间和图片均已做安全复核。
- 画面轨静音、主轨空置、字幕样式和坐标准确、CTA 包装只覆盖 CTA 区间、固定 CTA 贴纸参数正确、泡泡模糊数量等于画面段数减一、媒体路径无缺失。
- 后台结构 QA、剪映可见、前台播放、导出 MP4、上传和平台审核必须分别报告；没有对应证据时不得越级宣称完成。
