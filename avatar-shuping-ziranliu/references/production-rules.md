# 独立模式规则

## 配音和音频驱动

整篇配音是唯一声音来源。先生成/锁定全文，再按字幕分界截取开头；不在 HeyGen 输入开头文案让它重新说。正文不变但复用历史音频时，要比对当前文稿逐字一致；只有对应段落和 PCM 确切相同才可复用历史时码。正文已改字不能直接沿用整条旧音频。

截取清单记录全文音频 SHA256、截取音频 SHA256、起止时间、采样率、帧数、锚点和 PCM 前缀相等。上传前不再处理/变速这段音频；若最终主音频改变，重新截取并检查是否需要重生成，避免拿旧口型配新音频。

网页流程：单个场景 → 演示者 → 选定造型 → 上传/录制 → 上传音频 → 选择截取 WAV → 关闭语音镜像 → 添加音频 → 确认模型和画幅 → 生成。不得选上一次上传记录充数。上传、生成、完成、下载分别验证。Chrome 文件上传需扩展允许访问文件网址和正式站点/上传权限；权限可用时可以全自动执行，不把一次权限失败固化成永远人工上传。

当前默认 Gary look ID 为 `5502ae9359b946a3a9b4831375a89e22`，不是按 group ID 猜测；执行前核实实际 look 可用性。不要自动新建数字人或切换其他人物。MCP 返回的 engine 列表不等于网页产品支持列表；只选择实际工具支持的引擎。

## 画布、声音和字幕

- 画布 1080×1920、30fps。数字人源视频允许 720×1280；按真实尺寸填元数据，不将其声称为原生1080p。
- 主视频轨空置，3 段画面全部附加轨：数字人 → 女主齿轮衔接视频 → 女主正文单图。后两者来自同一个女主素材目录；数字人独立身份不受“全片同一女主”约束。
- 开场数字人时长等于语义开头时长 `B`；齿轮视频源长度至少1.833333秒。正文单图从 `B+1.833333s` 至终点。
- 开场字幕：Aa研宋9号，短单行可10号；坐标(0,0)，居中白色100%不透明，无描边，有黑色阴影；不生成英文。
- 正文中文字幕：系统字体8号，坐标(0,-0.24)，白色黑描边。英文系统字体8号，坐标(0,-0.35)，白色黑描边；逐条与正文中文相同时间码。
- 中文字幕每行最多17字，先由执行者完成语义及相邻边界审核，锁定后 `--keep-lines` 对齐；普通口播字幕首尾相接，唯一有意空档为齿轮1.833333秒。正文英文无空档无重叠。
- 开场和正文主配音各+10dB，素材自带声音全部静音。视频总时长等于全文音频时长+1.833333秒，不能把桥接漏算成原音频时长。
- 保留黑曜、暗角、正文“秘”贴纸、免责声明、标题和小标题、齿轮、心跳、“我的预设7”BGM；文案沿用原模式，正文标题按本篇替换。
- 两个画面切点各用独立1秒“泡泡模糊”材料ID，所有轨道终点不超出口播终点。

## 构建参数

`build_avatar_vertical.cjs` 是独立构建器，不调用旧自然流技能脚本。当前内置包装资产为 Mac 资产路径；Windows 可提供 ASR，不能直接把 Mac 路径当 Windows 素材。更换宿主需先显式定位同等资源，不覆盖原流程。

环境变量：

| 参数 | 用途 |
| --- | --- |
| `DRAFT_ROOT` | 目标草稿根目录；默认 Mac 剪映草稿目录 |
| `REFERENCE_ROOT` | 包装参考草稿根目录；默认 Mac 剪映目录，可与目标根分开 |
| `SOURCE_NAME` | 干净的音频+中文字幕源草稿名，字幕轨名“字幕”、配音轨名“配音” |
| `TARGET_NAME` | 包含“数字人竖版自然流”和实际女主目录名的新草稿名 |
| `AVATAR_VIDEO` | 已检查并对齐的数字人开头视频，绝对路径 |
| `GEAR_VIDEO` | 女主目录中的齿轮衔接视频，相对文件名或绝对路径 |
| `FEMALE_FOLDER` | 齿轮视频和正文图所在的女主目录 |
| `BODY_STILL` | 女主正文图片文件名 |
| `TRANSLATION_PATH` | 本篇正文英文字幕JSON，items包含material_id/start/duration/zh/en |
| `BODY_TITLE_TEXT` | 本篇正文标题 |
| `OPENING_MARKER_TEXT` | 开头最后一条字幕，默认“今天我们要聊的是” |

英文生成前从本篇新源草稿提取正文条目。翻译内容可复用，但只能按中文全文精确匹配；时间码和 material_id 必须取当前草稿，不复制历史时码。

构建器拒绝覆盖已有目录，拒绝视频源时长不足、正文图离线或元数据错误。草稿输出 `vertical_natural_flow_qa.json`（继承文件名，仅为此独立草稿的局部QA），并标记 `mode=avatar-shuping-ziranliu`。不复用旧母版的草稿ID。

## 验收

后台复查：原稿hash不变；新草稿ID独立；字幕逐字对应锁定分行；普通区间连续；中英正文时码相等；数字人只出现一次且始于0、止于B；数字人和女主视频静音；女主目录、正文图、命名一致；源视频长度有效；齿轮/正文/心跳同步；两个转场ID独立；无离线路径、超长尾部或黑帧。

剪映前台：核对开头和末条开场字幕、开场口型、两个转场、齿轮中段女主仍动、正文单图及标题/中英字幕同步、结尾字幕与声音。首次升级后字幕有时会变成50%透明，需以界面为准修正到100%。源路径声明不能替代前台检查。

用户亲自检查可记录“用户验收通过”，但不得伪称执行者完整试听或已导出。导出需实际文件存在、能解码，并核对时长/画幅/音视频流；上传和发布另行记录。
