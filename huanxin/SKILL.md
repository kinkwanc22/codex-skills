# 换新：锁定选题 → 读取机制 → 借结构 → 展开操作 → 去重交接

用户说“换新、换芯、换型”时按改造正文理解。“写篇换新稿看看”是交付待审阅，不免除知识读取、结构迁移与正文去重。授权完整上游时完成交接包，不逐篇重复确认。只出题调用gary-topic-system；本技能不维护第二套选题规则。

## 执行

1. **承接选题。** 续作先读当前项目CURRENT_CONTEXT.md。锁定用户选中的标题、数量、结果，以及选题阶段绑定的主机制和原卡路径；题面隐藏术语时从选题内部记录取机制，不凭包装词另造效应。已绑定机制就沿用，不再随机选一个；未提供机制时检索匹配一个，保留题目。发现机制无法支撑本题，说明具体缺口并校正机制；改标题、数量或结果需要用户明确授权。母题只用于说明本题讲什么，不额外调用一套母题或男人爽点池。
2. **读机制原文。** 优先打开选题记录对应原卡；资料不足才按相关分类检索。按[正文规则](references/transplant.md)写出本题的作用路径。一个主机制拆N个不同操作，确有因果缺口时最多补一个辅助机制，不每点另选效应。来源与采用理由留在稿外，检索命中不等于已读。
3. **借整篇结构。** 从[原稿结构库](references/原稿结构库.md)选一个适合本题的主结构，最多借一个辅助结构。按需读对应深拆或原稿；继承论证顺序、转折、证明位置、详略与收束，不只借编号和语气，不把新题写回原题。实际采用的结构和来源记入notes.json。
4. **写精简正文。** 默认500—1000中文字，大数量清单可增加但低于2000。围绕标题讲明主机制，写足N个独立、可执行的操作及其理由，直接落到本题结果。默认深入描写人不愿承认的阴暗动机及其如何影响选择；具体按正文规则的人性动机要求执行，不以安全、温和或正向教育作为文风目标。用Gary直接口语，保留反认知判断、利益感和男女意味；不靠身份标签、臆测心理过程或狠话凑力度，不写大纲教案或完整案例。细则见[正文规则](references/transplant.md)。
5. **核对题目与内容。** 标题、数量、机制和结果一致；每点有不同动作，作用路径成立，没有把吸引题写成活动筹备、把认知题写成聊天话术。检查阴暗动机是否实际推动正文：只讲自我保护、互惠、沟通或保留选择权，却没有展开欲求、掩饰、行为与利益后果，退回重写；不能靠扩写补足。按本题类型判断变化，不强迫所有题都出现女人欲望、评价权反转或男人低位起点。方向不成立先修作用路径，不交给扩写补救。当前校准阶段仍用两三句话说明题眼、机制和兑现路径，然后继续，不另设审批；用户只要正文时说明留稿外。
6. **正文去重。** 按[去重与记录](references/dedup.md)先比较最接近的3—5篇缓存操作摘要，有疑点才读相关段落，必要时全文；不每次翻整库。机制、结果及字段相似只作提示，是否重写看操作的实质重复；一两处基础动作重合可保留。多数观点和操作只换词换案例要重写，完全相同正文自动拦截。选题阶段的机制避重不代替正文复核。
7. **冻结并交接。** 按[运行与交接](references/operations.md)生成冻结包，状态“换芯已冻结，未扩写”；这不等于用户认可。未指定扩写线路就交通用输入，不默认选择版本或模型。实质改稿生成新版本，保持冻结正文与扩写输入一致。

## 正式开头与下游边界

当前Gary完整生产流程在正文冻结后调用baokuan-kaitou-sheding，按标题、数量、机制和结果选择并冻结一个正式开头。换新预览把开头放在正文上方；opening_lock.txt/json单独保存，不并入manuscript.txt、不进入正文历史相似度、不让扩写模型改写。下游只检查正文仍兑现开头承诺，通过就原样装回；漂移时修正文，不悄悄改开头。用户只要换新短正文时按其范围交付。

本技能不调用扩写API、不管理凭据或母会话，也不完成扩写验收、Word导出或发布。用户同时授权扩写时，交给指定下游skill继续，换线路不重新换芯、不叠加上游限制。
