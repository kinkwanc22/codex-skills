# 换新 skill

把当前Gary扩写前流程独立成可复用的上游。用户说“换新、换芯、换型”时，结合语境按同一改造正文的任务理解。用户只要选题就交选题，只要换芯就交换芯；授权完整上游时完成交接包，不在常规步骤中反复要求确认。

## 入口

- **生成选题**：2026-09-24 至 2026-10-24 优先执行[月度选题标准](references/topic-standard-2026-09-24.md)：每题限定技巧或操作数量，简短表达男人爽点与强结果。再读[选题与双账号规则](references/topics.md)，按用户数量和周期产出；默认一次给每个所需方向5个候选。已有明确批量要求时直接按量完成，不逐题追问。
- **把选题写成换芯稿**：有题锁定题目与数量；新题可以选原文作为整篇结构载体，不能因为套结构把新题写回原题。读[换芯规则](references/transplant.md)。
- **交给扩写线路**：读[运行与交接](references/operations.md)，导出纯正文或正文加案例提示。未指定线路就交通用包，不默认选择3.5、4.0、某个模型或某段会话。

## 写作前半程

1. 续作先读当前项目CURRENT_CONTEXT.md。题目、方向、数量与认可状态以当前用户要求为准；制作状态不等于认可、排期、发布。
2. 从[原稿结构库](references/原稿结构库.md)选一个整篇主结构。按需读[14篇深拆](references/14篇原稿逐篇结构深拆.md)或[新增六篇深拆](references/新增六篇原稿整体结构深拆.md)，必要时读对应原稿。继承论证顺序、转折、证明位置、篇幅轻重与收束，不只套编号或语气。
3. 运行本技能的知识检索，打开实际采用的卡片或连续原文。记录来源与采用理由到稿外；知识补充新题，不主导题目，不要求扫全库，也不把机器匹配当已阅读。
4. **先锁母机制，再写换新稿。** 每篇必须从心理学、社会学、生物学或 PUA 方法论中选择一个主效应、理论或术语；确有必要时最多增加一个辅助机制。主机制必须独立解释`男人原始卡点 -> 机制如何触发 -> 女人心理如何变化 -> 关系位置如何反转 -> 标题强结果如何发生`。找不到合适机制时重新检索或换路线，禁止用泛能力、泛建议或五条安全做法代替机制。
5. 用Gary直接口语写正文：普通题500—1000中文字，大清单可增加但必须低于2000。默认保持刺激、反认知和强煽动性：直接拆穿隐藏动机、利益冲突、男女位置变化和不执行的后果。每点有观点、因果、动作，解释所用术语；不写完整案例、导读或制作说明。温和、平和、安全化、关系咨询化或像建议清单的稿件不得冻结，除非用户明确指定安全版、合规版或温和版。
6. 按[去重与记录](references/dedup.md)完成历史筛查、六字段和逐点语义比较；与本批大小号也比较。不能将“词不一样”当作内容不一样。机器不替你自动批准语义复核。
7. 冻结manuscript.txt与交接信息，状态“换芯已冻结，未扩写”。复制出的扩写输入必须与冻结正文完全一致；换线路只改变稿外交接选项，不重新换芯或添加整套写作限制。
8. 当前Gary完整生产流程在换新阶段就调用 `baokuan-kaitou-sheding`，根据已冻结的题目、数量、核心机制和结果选择一个正式开头。把开头显示在换新稿上方，并单独保存为 `opening_lock.txt` 与 `opening_lock.json`；记录模板ID、变量、正文母题、数量和结果承诺。开头锁不属于manuscript.txt，不进入历史正文相似度，也不交给扩写模型改写。下游验收只复核扩写后的正文仍与开头的母题、数量和结果一致；一致时原样装回，不能重新创作第二个开头。只有扩写发生硬性母题或数量漂移时才重跑正文，不通过悄悄改开头掩盖。

本技能没有扩写API、凭据、母会话、正文验收或Word导出模块。当前Gary完整生产流程只在上游调用现有的 `baokuan-kaitou-sheding` 来选择并冻结最终开头，不在本技能内另造模板。若用户还授权扩写，交给其指定的下游skill/线路继续，不用上游规则悄悄替换下游设置。
