# 换新稿固定提示词

使用时只填写“随选题变化的字段”，不要删改后面的固定规则。若某个字段未提供，先按换新 skill 检索、判断并补齐；若无法找到能独立推出标题强结果的机制，先换机制或换角度，不要硬写。

## 随选题变化的字段

- 账号与方向：`[Gary大号 / Gary小号 / 其他已明确方向]`
- 选题标题：`[填写锁定标题]`
- 标题承诺的强结果：`[写成女人能被听见或看见的具体行为，不写抽象评价]`
- 主机制与知识依据：`[领域 + 准确术语/理论名称；B层知识卡ID/路径；已实际阅读的A层原文片段ID/路径及原句；证据等级与限制]`
- 贯穿全文的核心判断：`[一句反认知判断；它要解释整篇为什么成立，不是主题复述或口号]`
- 逐级推进链：`[按标题数量列出每一阶段的任务；每步如何承接上一步，并把关系推向强结果]`
- 原始卡点与男人动作：`[男人当前误判/错误动作，以及换新后需要呈现的动作]`
- 结构载体：`[原稿/知识卡/指定结构；没有指定则从原稿结构库选择一个]`
- 数量与内容形态：`[例如六条规则、五种用法、连续论证；必须与标题一致]`
- 参考材料与排除项：`[原文、知识库路径、已用机制/需要避开的同质化路线]`
- 开头要求：`[调用开头系统匹配正式模板；如用户指定原样保留则粘贴并锁定]`
- 特殊交付要求：`[字数、是否留案例位、目标扩写线路等；未指定则按默认值]`

## 固定提示词正文

请基于以上字段，完成一条可交给后续扩写线路的 Gary 换新稿。先核对选题、历史内容和知识来源，再锁定一条主机制与一个整体结构，之后写稿。使用知识库机制时，必须实际读取并同时记录B层知识卡与其A层原文片段；不可只凭索引、摘要或记忆写作。换新应迁移结构、论证顺序与证明方式，不照抄原稿表达，也不能把新题写回原题。

### 机制硬规则

- 主机制只能来自心理学、社会学、生物学或 PUA 方法论，且须与两性关系、人际吸引或人类行为直接相关。一个主机制即可；确有因果缺口时最多加一个辅助机制，不能把多种效应拼盘。
- **主机制的准确术语必须进入正文，并在正文用自然口语说明它是什么、如何作用，以及它怎样推动本题的关系变化。**不能只在标题、提示词、脚注或稿外备注里出现术语；不能只贴名词不给解释；也不能把术语解释成泛泛道理。
- 正文因果链必须完整：男人的原始卡点/动作 → 机制被触发 → 女人产生具体心理变化 → 关系评价权或推进权变化 → 标题承诺的强结果发生。每个分点服务于同一机制，分别承担触发、放大、验证、反转或兑现，不得改词重复。
- **先立一条贯穿全文的核心判断，再设计分点。**核心判断必须能解释标题结果为什么会发生，并统领同一主机制；不能只是把标题换种说法，也不能落成“别付出、要有边界”一类通用建议。
- **分点必须组成有方向的推进链，不是并列清单。**动笔前先在稿外为每点标明阶段任务、承接关系和女性可观察到的变化。各点按需要承担“暴露错误预期→改变男人动作→触发/放大机制→出现女性反馈→关系位置变化→兑现标题结果”等不同任务；具体顺序服从选题，不能机械套阶段名。相邻两点必须有因果或压力递进关系，不能调换顺序而不影响全文。
- **逐级兑现标题结果。**每一阶段都要让关系状态比前一阶段更靠近标题结果；结尾必须呈现强结果本身及其发生路径，不能只总结原则或停在“男人停止单向供给”。如果标题承诺女人主动投入，须写出她从接收、回应到主动拿出时间/行动/资源并推进关系的可见变化；不能用男人单方面撤回供给代替女人主动投入。
- 正文只呈现自然的论证和口播，不把“核心判断、阶段任务、推进链”等后台字段念出来；分点编号可以保留，但不能让每点都退化成同句式的“不要……要……”。
- 机制说明要准确，不虚构研究结论、科学定律、个人经历或必然效果。知识卡与原文片段的证据状态必须写入稿外控制信息；单一高赞来源只证明该来源这样表述，不单独证明其机制普遍成立。知识卡、案例和资料来源写在稿外备注，不要把“知识库里用某某效应解释”这类后台说明念进正文；正文应直接自然说出准确术语并解释。

### 选题与结果硬规则

- 保持标题的对象、母题、数量和强度，不擅自降成聊天技巧、邀约话术、自我提升或关系咨询。
- 把标题结果拆成具体、可观察的女性行为，并在正文真正兑现；不能用普通回应、接受帮助、愿意继续互动等较弱信号冒充主动投入、进入暧昧或关系升级。
- 写前检查与历史稿、本批其他稿的母题和机制是否实质重复；不能只靠换词制造“新题”。

### 表达与结构硬规则

- 保留用户认可的 Gary 表达方向：直接、有冲突、反认知、煽动性、轻微阴谋论、有欲望和结果感；可以暗黑、刺激，但要靠利益冲突、错误代价、隐藏动机和位置反转，不靠空喊、辱骂或堆强度词。
- 不写成温和建议、平和分析、安全提醒或泛泛的“做好自己”；每一部分都要有判断、因果和具体动作。
- 使用自然口语，避免 AI 套话、讲课腔、抽象术语堆叠、导读和制作说明。机制术语只在能解释本题时出现，并当场讲清。
- 默认500—1000中文字；大清单可以适当增加但低于2000字。除非用户指定，不写完整案例；不在开头后马上放案例。需要案例时按要求留稿外案例位。
- 开头按开头系统选用与本题、数量和结果匹配的正式模板；不要自造固定模板，也不要把模板中不适配本稿的变量硬塞进来。用户给出并锁定开头时必须原样保留。

### 输出

1. 先列稿外控制信息：标题、主机制（领域/术语）、机制选择理由、贯穿全文的核心判断、逐点推进地图（阶段任务/承接关系/女性可观察变化）、强结果的可观察判据、采用的结构来源、历史去重结论。
2. 给出按开头系统匹配的开头；在完整生产流程中记录模板ID与变量，并与正文分开锁定。
3. 给出完整换新稿。正文中必须自然出现主机制准确名称及其解释；不得把稿外控制信息混进正文。
