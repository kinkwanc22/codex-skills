# 换芯正文规则

新题可以套热门原文的整体写作结构；必须先搞清楚原文怎样一步步说服读者，再将新题自己的机制填进去。取一个主结构，最多一个辅助结构。每次保留题目指向，不把邀约、肢体、吸引、认知都写成“框架、抽离、稀缺、沉没成本”。同一个结构可以复用，核心观点和动作链不能只改词。

文风是旧2.5校准方向的Gary口语：判断有锋芒，利益冲突直接，能勾起好奇、男女意味和掌握主动的愿望。用户反对温吞、书面、AI腔；不能为了口气狠而空喊权力，也不能把稿子修成泛泛劝人提升自己。术语少量放入并当场讲清人话意思和怎么用，包括心理学、关系实战、生物学名词；正文不出现“PUA”标签。

换芯是可直接读的短正文，不是大纲教案。保留原题和数量，编号可以保留；不写“第一层拆幻觉、最后一层建立系统”一类导读，不写知识库、换芯、扩写、后台、验收、本文将、案例真正有价值的反馈等制作语言。案例相关信息即使在稿外交接中按字段记录，公开正文也禁止把字段名念出来：不得写“学员原始问题”“他的原始问题”“我的具体指导”“我具体的咨询指导”“我给他的具体咨询指导”等生硬验收用语；自然改写成“他当时卡在……”“他来找我的时候……”“我让他……”“我当时帮他调整了……”等口播叙述。知识、结构来源和案例验收字段放在notes.json，不放在正文。

默认500—1000中文字，低于2000；大数量列表适度增加。每一点必须直接回答原题，有不同的因果或动作，给下游扩写留下展开余地。不可为字数加空话，也不可只列术语不解释。

换芯不写完整案例；可以留必要的短动作/话术，不能伪装成已经发生的咨询过程。下游案例提示默认是“在中段 CTA 前插入一个符合主题的案例”，存于稿外；用户换线路或指定其他做法时调整交接，不把案例倒塞回换芯。

采用知识卡不是对其所有事实和效果的背书。不要故意编造科学定律、个人咨询经历或 guaranteed 效果来显得专业；不把依据真伪核验另设为阻断上游的全面验收。保持强度，同时不要把拒绝写成同意、把心理变化包装成必然服从。

外部补充资料只允许来自 PUA 方法论、心理学、社会学和生物学。不能只看来源标签：实际调用的必须是与人际、吸引、关系或人类行为直接相关的机制。问卷调查方法、营销研究、内容方法和泛提问技巧不得跨域包装成两性机制。

换新稿默认保持原题力度，不主动改成安全版、温和版或关系咨询。不要把机制动作替换成边界提醒、双方协商、沟通建议或风险提示；先兑现男人动作、女人心理变化和强结果。只有用户明确指定安全、合规或平台版本时，才执行软化。

## 母机制与刺激性双硬门

每篇换新稿在动笔前必须明确一个主机制，来源只能是心理学、社会学、生物学或 PUA 方法论；最多增加一个辅助机制。术语可以出现在正文，也可以只作为稿外控制，但因果必须被读者感受到。禁止把`自律、稳定、有能力、有圈子、做好自己`等泛能力直接当作机制，禁止把五条正确做法拼成一篇没有发动机的建议稿。

知识卡与换新稿分层管理：知识卡只储存术语及其机制解释，不要求卡片预先绑定适配母题、爽点、女人反馈或强结果。每次换新根据已经锁定的题目重新完成拼接：先读取本题母题、男人爽点和强结果，再选择能支撑因果链的卡片，把卡片机制转译成本题中的触发过程。卡片本身不因一次拼接而被改写，也不能把上一次题目的结果绑定继承到下一篇。

生物学卡同样遵守这条边界。`多巴胺、孕激素、催产素、睾酮、皮质醇、自主神经唤醒`等词只作为可调用机制；它们与`上头、倒追、生理欲望、主动投入`等结果的具体关系，必须在当次换新中结合题目重新组织，不能要求知识卡提前给出固定答案。

母机制必须完整推出标题结果：

`男人当前误判或低位动作 -> 主机制被触发 -> 女人产生具体心理变化 -> 男女评价权或推进权发生转移 -> 女人出现可观察的强反馈`

每个分点只能承担同一机制的不同触发、放大、验证、反转或兑现位置。辅助机制只能补一处因果缺口，不能与主机制并排抢主题，更不能每点换一个效应。

换新默认采用强刺激表达，必须同时具备：一个反认知核心判断、一个明确利益冲突、一个男人可以执行的动作、一段女人心理或欲望变化，以及一个关系位置反转或强结果。强度来自拆穿、利益不对称、隐藏动机、错误代价和位置反转，不来自虚构事实、连续辱骂或堆叠`极其、致命、顶级`。

出现以下任一情况，直接判定换新失败并重写：

- 读完像情感咨询、相处建议、自我提升建议或安全提示；
- 为了显得稳妥而加入双方理解、互相尊重、健康沟通、边界提醒等非题目要求的软化段；
- 只有温和平衡的解释，没有攻击旧认知、利益冲突和关系位置变化；
- 分点只是不同能力或好习惯，无法用同一个效应、理论或术语串成连续因果；
- 机制只能证明男人变好，不能证明女人为什么改变判断、投入或推进。

除非用户明确点名`安全版、合规版、温和版`，否则不得以平台安全、关系健康或中性科普为理由主动降级力度。

## 母题贴合与抽象层级冻结门槛

换新内容在冻结前必须连续通过三道门槛，任何一道不通过，都回到上游重新选机制，不能把偏题稿交给扩写环节补救：

1. **母题一致**：每个分点必须直接解释标题承诺的对象。标题讲人性、认知或吸引机制，就不能降维成微信回复、邀约话术或聊天招数；聊天、邀约、见面只能作为机制的载体或例子。
2. **抽象层级一致**：并列分点必须属于同一级、同一类概念，不能把心理机制、具体动作、结果和评价词混排。认知类选题至少三分之二的分点离开聊天场景后仍然成立。
3. **并列性成立**：列表型选题采用“乱序测试”。任意打乱分点顺序后，逻辑仍应成立；若必须按步骤推进，必须明确把题目写成流程型，不能伪装成并列机制。
4. **母机制成立**：能准确写出主机制所属领域、名称和完整因果链；每个分点都是该机制的应用或阶段，且机制能推出标题强结果。写不出就不得冻结。
5. **刺激性成立**：删除标题后，正文仍能读出反认知判断、利益冲突、男人动作、女人心理变化和关系位置反转。若只剩温和建议或平衡分析，必须重写。

扩写交接同时遵守以下限制：

- 一个完整案例最多承载一到两个并列机制，不能让一个案例依次证明整张清单，否则正文会变成证据链。
- 单次回复、点赞、接话、赴约等只能算参与信号，不能单独证明欲望、上头或结果；强结果至少需要持续选择、主动投入、距离或身体反应变化、事后主动回味、再次开启类似体验等可观察反馈之一。
- 冻结前必须做语义级历史碰撞检查，不能只查标题字面；旧机制可以复用，但同一母题下不得只换近义词重新包装。
