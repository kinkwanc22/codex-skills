# 可选母题参考

这10个方向来自旧版已认可标题的归纳，只在需要时参考，不是每批必读文件、固定配额或必选前置步骤。

| 母题 | 保留的选题逻辑 |
|---|---|
| 泡妞与赚钱 | 情场与事业共通的利益、竞争、交换或风控逻辑 |
| 搞定顶美 | 顶美的隐秘需求、择偶标准与吸引突破 |
| 男性迭代 | 从普通男人或贝塔到有吸引力的强者 |
| 男人内核 | 框架、边界、判断力与主导权 |
| 研究女人 | 女性心理、人性暗面与隐秘择偶需求 |
| 摄心术 | 触发上头、欲望和主动投入的心理机制 |
| 女性资源与圈层 | 认识女人、突破圈层与持续获得异性机会 |
| 男女筛选与博弈 | 追逐、选择和投入的位置变化 |
| 关系推进 | 从认识、聊天、邀约到暧昧与升级关系 |
| 雄性魅力与性张力 | 本能吸引、生理欲望与短期关系 |

用户指定方向、要求沿用旧母题或需要补充内容方向时，读取本页。普通出题默认直接抽机制；执行者可在合适的个别题中借用这些方向，不要求每批使用，也不要求每题先匹配母题。

使用母题时，它只限定讲什么：仍按“抽机制→随机匹配强结果→确定操作数→标题”执行，机制和结果须与该方向匹配。不要额外加入爽点、母题分析或完整因果证明，不强行把母题名称塞进标题，也不把旧标题重新当成固定模板。
