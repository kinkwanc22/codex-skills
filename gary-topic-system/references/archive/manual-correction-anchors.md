# 人工校正锚点

本页保存用户亲自改定的标题与可迁移判断。它们用于校准母题贴合、力度和自然表达，不是固定模板，也不能靠替换名词反复重出。

## 当前有效锚点

1. `从普通到拥有强大吸引力的六次迭代，让女人从高位到主动对你释放男女信号`
   - 先写男人的完整身份跃迁，再写女人位置与行为的明显反转；不是泛泛“提升魅力”。

2. `利用自我验证效应，让女人的隐秘择偶标准为你开启，主动倒追你。`
   - 机制直接服务母题；中段给出带欲望感的心理对象，结尾落到倒追，不用弱反馈收尾。

3. `泡妞与赚钱共通的十条利益规则，通过认知迭代，拿下顶美顶薪双结果`
   - 双领域题保留泡妞与赚钱的共同母题，数量、认知动作和双结果一次说清，不拆成两条无关承诺。

4. `用自我实现预言彻底重塑身份，从贝塔迈向阿尔法，让女人主动对你释放男女信号`
   - 机制作为主动作，直接说明重塑对象；再回扣身份母题和女人的主动行为。原稿旧数量无需机械继承。

5. `摄心术：八大暗黑心理学，怎么样用不同的心理机制，反复触发女人对你的上头。`
   - 合集型母题必须保留多机制结构，可以调整数量；不能用单一效应替换成另一篇单机制题。

6. `搞定顶美的四种稀缺匹配方式，撬开她不说出口的隐秘择偶需求，让她主动为你投入。`
   - 顶美题点明“不说出口的隐秘择偶需求”；没有既有投入时用“主动投入”，不误写成“加码”。

7. `利用社会交换理论，建立五条强者筛选规则，让女人主动倒追你、为你付出关系成本`
   - 机制、强者位置与两个递进结果形成同一条线；认可的是组合逻辑，不是要求所有标题都采用该句式。

## 持续学习规则

- 每次追加时记录日期、助手原版、用户改版和一至三条可迁移判断。
- 用户只说“不错”但没有手改，记作正向信号，不升级成永久硬规则。
- 新校正与旧规则冲突时，保留旧记录并明确标注哪一条被撤销或被新指令覆盖；不能直接抹掉历史，避免日后误恢复。
- 只修改选题层。正文、开头和扩写反馈分别进入对应系统。

### 母题与简化模式

2026-09-30用户明确以“泡妞与赚钱”说明：简化过程仍保留选题母题，机制和数量可以变化。其“共通的10个风控效应”用于说明组合意图，不能据此发明十个效应。单一机制拆十种应用，应写“十种操作／用法”，且两端都成立。

### 无知识库测试的执行失败

2026-10-01助手未调用选题Skill，直接交付十题，如`打破好人印象的五种调情方法，让女人主动跟你暧昧`、`制造约会后劲的四种互动方法，让她回去以后还想见你`。用户反馈：`为什么选题总是不按照选题规则呢？选题不是应该有一个选题 skill 吗？`

失败判断：跳过Skill、未锁主机制、多题用泛技巧撑数量、部分收益停在弱反馈。不是判定所有“暧昧／主动想见”表达都禁用：结果必须按本题强结果及主动推进程度判断。修正要求是“不读知识库不等于不调用Skill”，不是恢复每题读取知识库。

本轮后来重出的十题尚无明确认可，不能作为成功样本。关于“别的对话效果差是否由记忆混杂造成”仅有用户疑问，原因未实测，不记录成已证实结论。

## 2026-09-30 默认选题公式简化：默认模式不调用爽点

用户确认当前选题逻辑不需要先创造大母题或完整逻辑，也不需要单独匹配男人爽点。生成顺序改为：

`强结果 -> 从现有机制库匹配一个机制 -> 添加明确操作数量 -> 直接写标题`

强结果本身就是爽点。标题可以直接使用简单公式，例如：`怎么样通过峰终定律的六个操作，让女人主动倒追你`。选题阶段只完成机制、数量与强结果的组合；机制的完整解释、动作链和因果证明留到换新与扩写阶段。

### 同日追加：爽点模式独立保留

用户确认以后默认使用上述简化公式，但要求原有“机制＋男人爽点＋强结果”作为另一套独立模式保留。普通出题不调用爽点池；只有用户明确要求爽点版时才启用。两套模式互不覆盖，也不因一次模式校正删除另一套。
