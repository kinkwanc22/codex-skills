# 人工校正锚点

本页保存用户亲自改定的标题与可迁移判断。它们用于校准母题贴合、力度和自然表达，不是固定模板，也不能靠替换名词反复重出。

## 当前有效锚点

1. `从普通到拥有强大吸引力的六次迭代，让女人从高位到主动对你释放男女信号`
   - 先写男人的完整身份跃迁，再写女人位置与行为的明显反转；不是泛泛“提升魅力”。

2. `利用自我验证效应，让女人的隐秘择偶标准为你开启，主动倒追你。`
   - 机制直接服务母题；中段给出带欲望感的心理对象，结尾落到倒追，不用弱反馈收尾。

3. `泡妞与赚钱共通的十条利益规则，通过认知迭代，拿下顶美顶薪双结果`
   - 双领域题保留泡妞与赚钱的共同母题，数量、认知动作和双结果一次说清，不拆成两条无关承诺。

4. `用自我实现预言彻底重塑身份，从贝塔迈向阿尔法，让女人主动对你释放男女信号`
   - 机制作为主动作，直接说明重塑对象；再回扣身份母题和女人的主动行为。原稿旧数量无需机械继承。

5. `摄心术：八大暗黑心理学，怎么样用不同的心理机制，反复触发女人对你的上头。`
   - 合集型母题必须保留多机制结构，可以调整数量；不能用单一效应替换成另一篇单机制题。

6. `搞定顶美的四种稀缺匹配方式，撬开她不说出口的隐秘择偶需求，让她主动为你投入。`
   - 顶美题点明“不说出口的隐秘择偶需求”；没有既有投入时用“主动投入”，不误写成“加码”。

7. `利用社会交换理论，建立五条强者筛选规则，让女人主动倒追你、为你付出关系成本`
   - 机制、强者位置与两个递进结果形成同一条线；认可的是组合逻辑，不是要求所有标题都采用该句式。

## 持续学习规则

- 每次追加时记录日期、助手原版、用户改版和一至三条可迁移判断。
- 用户只说“不错”但没有手改，记作正向信号，不升级成永久硬规则。
- 新校正与旧规则冲突时，保留旧记录并明确标注哪一条被撤销或被新指令覆盖；不能直接抹掉历史，避免日后误恢复。
- 只修改选题层。正文、开头和扩写反馈分别进入对应系统。
