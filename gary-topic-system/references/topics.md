# 选题与双账号规则

先读[当前月度标准与认可七题](topic-standard-2026-09-24.md)：2026-09-24 至 2026-10-24，每题必须限定技巧或操作数量。默认按2026-09-30简化公式：先从[强结果调用池](strong-result-pool.md)选择结果，再从现有机制库匹配一个机制；强结果本身就是爽点。用户明确要求爽点版时，切换到独立的[男人爽点调用池](men-payoff-pool.md)，但不改变默认公式。

## 结果与用词

用户只要两种力度：从普通到极致，或结果本身足够刺激。题目直说读者能拿到什么，同时给出可展开的机制或方法。避免“相处体验、欣赏、好感、相处舒服、拉近距离、心照不宣”等作主要收益；也不要只分析“她的八种变化”却没有读者能做什么。

自然用词参照：顶美、开车、上头、勾起欲望、暧昧、肢体升级、升级关系、主动投入、主动想见你。不要把标题写成“想被抱、想接吻、当面说什么、主动发自拍”等单一小场景。强度来自结果反差、隐藏动机和利益冲突，不靠连续添加“顶级、致命、极其”。不把同一欲望词重复到所有标题。

## 两个账号

- 大号：吸引机制、研究女人、男女关系、人性、商业利益和个人提升，重认知深度与可操作判断。纯个人成长若与这个账号的男女关系定位无关，不用套两性词硬凑；用户另定范围时服从新范围。
- 小号：技巧比重更高，聊天、邀约、肢体升级/关系推进交替；不能七天都变成聊天或调情。
- 一周双号默认每号7条。一月60条默认两个号各30条，按用户实际更新量调整。
- 可沿用已获认可的一周小号分配：聊天2、邀约2、肢体升级2、人性认知1，打散排列。大号不机械继承小号这个比例。
- 单号未指定方向比例时，短期与认知约2:1是起点，不是所有账号的硬配方。

## Gary默认客群与关系阶段

Gary大小号的默认核心客群，是找不到女朋友、缺少女性资源、不会认识女人、不会制造吸引或不会把关系从陌生推进到恋爱的单身男人。除非用户明确指定长期关系主题，否则选题必须从“尚未得到女人、尚未进入稳定关系”的现实起点出发。

合格推进范围包括：认识女人、获得联系方式、聊天建立男女意味、勾起见面欲望、突破邀约阻力、第一次约会、识别双向信号、在明确回应下升级关系，以及最终脱单。可以把普通、低位或不会推进的单身男人塑造成高位男人、有选择权的男人，并把女人主动投入作为极致结果；“高位男人”既可以作为目标，也可以作为方法对照，不能因为核心客群目前单身就禁用。

直接淘汰以下默认前提：已经有女朋友或稳定对象、女人已经强烈占有或吃醋、双方已经进入长期关系后再处理害怕失去、控制、变心、忠诚、冲突修复、关系维护或长期尊重。禁止的是恋爱后的关系分析，不是“高位男人”概念。女性心理和人性暗面要用于帮助单身男人完成吸引、筛选、前期推进与身份升级。

## 结构轮换

数字清单＋全剖析/完整版解析为主，搭配结果导向＋做对N件事、反常识、较大数量认知差、心理机制与底层逻辑、错误避坑。保持用户认可的标题结构，换主题、角度、数量和真实内容，不强行按固定星期复刻旧表。

候选内部记录账号、方向、标题、预计独立机制；用户只要选题时，公开只交编号标题。标题阶段先做题目/机制概览去重，不为五个候选运行整套冻结流程。用户仅以序号筛选时使用当前展示列表；缺少当时列表不能凭空补全历史候选。

已认可语感：从朋友区到让女人上头，高手升级关系的五个关键，全剖析；第一次见面就能勾起女人欲望的六种男性魅力，全剖析。它们是语感示例，不作为每批重复选题。

## 选题组合逻辑：强结果 + 机制 + 数量

直接生成时不要求重新创造母题，也不单独调用男人爽点。可先沿用用户给定方向或下方已有母题，在该方向内选强结果、匹配现有机制、确定操作数量；没有指定方向时仍可直接成题。强结果就是观众爽点：可选`主动倒追、产生生理欲望、进入短期框架、获得女性资源、主动付出成本、离不开、拿下顶美、驯化女人、成为强者`等终点。

标题阶段不需要证明完整因果链，也不需要解释男人获得了什么中间位置。机制与强结果能够形成直观的达成关系即可。默认可以直接使用：

- `怎么样通过【机制】的N个操作，让女人【强结果】`
- `利用【机制】的N种方式，让女人【强结果】`
- `掌握【机制】的N个关键，让女人【强结果】`

例如：`怎么样通过峰终定律的六个操作，让女人主动倒追你`。不要因为句式简单而强行加入母题、身份跃迁、筛选权、资源位置或额外爽点。

### 已有选题母题（简化模式可调用）

2026-09-30 用户同意尝试在简化模式中调用下列已有方向。它们由此前确认过的标题归纳，不是新的封闭清单、必选配额或每批都要重复的固定标题。母题负责限定讲什么，机制负责提供本次内容变量；不要把母题、知识机制和标题句式混为一层。

| 母题 | 保留的选题逻辑 |
|---|---|
| 泡妞与赚钱 | 情场与事业共通的利益、竞争、交换或风控逻辑 |
| 搞定顶美 | 顶美的隐秘需求、择偶标准与吸引突破 |
| 男性迭代 | 从普通男人或贝塔到有吸引力的强者 |
| 男人内核 | 框架、边界、判断力与主导权 |
| 研究女人 | 女性心理、人性暗面与隐秘择偶需求 |
| 摄心术 | 触发上头、欲望和主动投入的心理机制 |
| 女性资源与圈层 | 认识女人、突破圈层与持续获得异性机会 |
| 男女筛选与博弈 | 追逐、选择和投入的位置变化 |
| 关系推进 | 从认识、聊天、邀约到暧昧与升级关系 |
| 雄性魅力与性张力 | 本能吸引、生理欲望与短期关系 |

使用方式：方向可以沿用，机制、数量和强结果按本次内容替换，不把“泡妞与赚钱”固定成“十条交换逻辑”。例如用户给出“泡妞与赚钱的10个共同逻辑”，保留双领域共通性和指定数量，匹配交换、竞争或其他有来源的方法；每条必须在情场和事业两端成立，不能五条泡妞加五条赚钱拼成十条。

“泡妞与赚钱共通的十种风控操作，拿下顶美顶薪双结果”是表达示意，不是已验证的机制卡或效果证据。实际出题仍须匹配现有知识库，不把“风控效应”自行命名为新效应。一个机制拆十种应用，写“十种操作／用法”；“十个效应”指十个不同效应，不能与单机制的十种应用混用。用户指定10时不强行改成默认4至8。

简化模式仍只交简短编号标题；完整解释和动作链留到换新、扩写。此方向调用不启用爽点池，也不改变独立爽点增强模式。

### 独立爽点增强模式

只有用户明确要求爽点版时，才采用`机制＋男人爽点＋强结果＋数量`。爽点写男人先获得的利益或位置变化，强结果写最终兑现；二者不能同义重复。该模式单独运行，不取代上面的默认简化模式。

### 数字结构：本月每题必填

当前月度标准覆盖旧“数字可选／复杂时保留无数字版”条款。每题给出技巧、方法、操作或可执行关键的明确数量，依据内容容量定数，不虚增、不凑点。正文必须逐项兑现；不足时调整数量或选题。

句式灵活使用“利用【机制】的N种技巧”“掌握N种【方法】”“用N个操作【核心动作】”，按月度标准的认可样例表达，不机械统一句式。

## 母机制强制锁（2026-09-23升级）

每题只匹配一个主机制，来源只允许心理学、社会学、生物学或PUA方法论。选题阶段只做机制名称、强结果和数量的组合，不提前展开完整因果证明；正文换新时再解释机制怎样实现标题结果。不得为追求新鲜发明伪效应。

## 常识型新机制融合路径（2026-09-12验证）

在保留账号热门骨架的同时，可以从知识库持续调取“受众听过、现实中确实存在、但Gary账号过去很少用”的心理学或人性机制，作为新一批选题的母机制。优先选择富兰克林效应、投射效应、认知失调等具有大众认知基础的概念；不要为了显得新鲜而发明“情绪余震、选择幻觉”一类怪词，也不要使用“出丑效应、吃透”等用户已经否定的包装。

组合方式是：一个可识别的心理机制或人性规律＋明确数量的用法/节点/操作＋男人能够拿到的刺激结果。热门标题提供力度、结果和完整剖析感，新机制提供内容变量；不能只把旧爆款换一个术语重新发布。机制和结果允许分别复用，但两者不能长期同时不变；若都需要复用，至少改变数量、场景、动作链或证明方式。

不要求每一条题目都显式写出心理学名词。每周可约一半在标题中直接显示新机制，另一半继续使用雄性魅力、泡妞与赚钱、人性暗面、关系节点等大选题，避免账号变成心理学名词列表；但这些未在标题中显示术语的题目，进入换新正文时同样必须具备一个隐性的四域母机制。

当一个机制本身足够支撑全文时，把它作为唯一母机制，再拆成同一级的不同用法或场景。不要为每个分点再添加一个新机制，也不要拼成“机制A→机制B→机制C”的证据链。每个用法都必须是男人能执行的操作，最终落到女人主动投入、主动推进、反复上头等强结果。

已验证样本：`富兰克林效应的五种用法，让女人从被动回应到主动投入`。本题用同一个富兰克林效应拆成专业判断、二选一、纠正误判、轻量闭环、结果承接五种应用；没有退化成泛泛的“让女人帮忙”，也没有接入自我知觉、承诺一致性、蔡格尼克效应的多机制证据链。用户在普通2.8完整扩写后明确评价“效果不错”，可作为此路径的正向参照，但不得原题反复重出。
