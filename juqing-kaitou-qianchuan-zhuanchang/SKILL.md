# 剧情开头千川续写转场

把短剧情已经制造出的情绪、反差或关系结果，提炼成一段可直接配音的旁白，放在剧情与固定 CTA 之间。写作前优先从 Gary 知识库检索一张真正贴合剧情因果的知识卡片或心理学效应，用它解释画面为什么会产生这个结果。转场既要承接观众刚看到的画面，也要为 CTA 打开需求，不能变成剧情复述、普通总结或第二条独立文案。

## 默认交付

- 默认只交付一版完成稿；用户要求对比时再给备选。
- 默认时长 `18-25` 秒，优先控制在 `20-23` 秒，`25` 秒为硬上限。没有实际 TTS 时，按自然口播控制在约 `80-110` 个中文字符，并明确时长是估算；有指定音色或语速时以实际音频为准，超时就压缩。
- 交付可直接用于 TTS，不加标题、序号、舞台提示、引号说明或 CTA 占位符。
- 用户给了固定 CTA 时，先读懂 CTA 的承诺和入口，但不得改写、压缩或提前复述它；用户未给 CTA 时，转场收在“问题机制或能力缺口”上，保留自然接入空间。
- 使用了知识库内容时，在 TTS 正文之外用一行简短标明知识依据，例如 `知识依据（不进TTS）：B-018 标签效应`；不得把卡片编号、文件路径或检索过程念进口播。
- 批量处理时，在 TTS 正文之外同时记录 `热门开头骨架`、`句式功能` 和 `知识依据`；这些记录用于去重，不进入配音。

## 批量变体与热门开头对接

批量稿不能只把同一句“为什么这句话能……”替换关键词。每条剧情都要先从用户已经确认的热门开头系统中选一个适配骨架，再把知识卡嵌入该骨架的机制解释。热门开头负责第一拍的传播力度，知识卡负责解释剧情为什么成立，二者不是两段并列的开场白。

写作前按以下顺序选择：

1. 读取可访问的 Gary 开头系统索引、用户改写对照库和当前语感规则；只使用用户明确教过或确认过的开头形式，不调用旧泛化模板。
2. 根据剧情的主要传播点，给它标记一个句式功能：`强判断`、`结果先行`、`短问短答`、`身份落差`、`反常识反差`、`损失提醒` 或 `直接指令`。
3. 从该功能对应的热门开头骨架中抽取可迁移结构，不整段复制无关主题。保留骨架的力度、句序和结果导向，把剧情关键词替换成当前可见动作或关系结果。
4. 再把已检索的主知识机制放入第二拍或第三拍：可以用“这背后是……”直接命名，也可以先讲因果、最后落出效应名称；不要每条都用同一种知识卡引入句。
5. 批量相邻稿件不得同时重复 `句式功能 + 热门开头骨架 + 知识卡 + 收束句式` 四项组合。知识卡可以跨批复用，但必须更换剧情入口、开头功能、解释角度或动作链；同一剧情的 A/B 版本则共享一个开头，不额外引入变量。

推荐轮换表（不是硬顺序）：

| 句式功能 | 适合的剧情信号 | 转场入口方向 |
| --- | --- | --- |
| 强判断 | 角色态度明显反转 | “女人真正上头的，从来不是……” |
| 结果先行 | 出现主动靠近、主动投入 | “嘴上还在拒绝，身体已经……” |
| 短问短答 | 台词有双关或巧妙回击 | “为什么一句……就能……” |
| 身份落差 | 关系称呼、标签、位置发生变化 | “你以为是在开玩笑，其实是在……” |
| 反常识反差 | 表面推开，实际推进 | “看起来是在后退，实际上……” |
| 损失提醒 | 男方错过窗口或表达失误 | “你越急着证明，越容易把……” |
| 直接指令 | 剧情展示一个可复制动作 | “记住这个动作，关键不是……” |

开头骨架必须服务当前剧情，不能为追求变化而硬塞“女人最隐秘的欲望”“顶美”等与画面无关的词。每条转场只保留一个主判断、一个主机制和一个主要结果。

## 知识检索

写正文前，先把剧情拆成四个检索要素：关系阶段、男方动作、女方可见反馈、发生变化的心理位置。以这四项组合检索，不能只拿一句台词或一个热词机械匹配。

Mac 当前知识库的优先顺序：

1. B 层知识卡：`/Users/kin/Gary 男性情感/Gary 男性情感/02_B高价值知识`
2. 外部精炼知识卡与原子知识块：同一目录下的 `08_提炼记录`、`09_外部原子知识块`、`10_外部精炼知识卡`
3. 跨来源模块：`/Users/kin/Gary 男性情感/Gary 男性情感/02_B高价值知识/09_跨来源聚合`
4. A 层可搜索正文只用于补足上下文或核对原始表述，不应优先于已经提炼的知识卡。

如果绝对路径移动，按上述层级名定位同一知识库；找不到时明确说明没有完成知识库检索，不得把模型常识冒充已调取的卡片。

每条转场最多选一个主机制：

- 优先选择卡片的因果链同时吻合“动作、反馈、关系阶段”的机制，而不是名称听起来最抓人的机制。
- 优先使用受众容易理解、现实中确实存在的概念，如标签效应、富兰克林效应、投射效应、认知失调、锚定效应；不得发明新效应或生造术语。
- 找到贴合卡片时，保留卡片真正支持的因果边界，不擅自补成必然结果。
- 没有足够贴合的命名效应时，可以使用知识卡里的具体人性机制，不强行给它安一个心理学名称。
- 不堆叠多个效应。一个短转场只解释一个因果核心，知识是剧情的解释器，不是术语展示。

## 写法

从剧情中只抓一个最有传播力的瞬间：关键台词、人物态度反转、身体反应或关系推进结果。围绕它完成以下逻辑，不必机械分成四句：

1. 用剧情里的关键台词或可见结果提出一个短而有力的问题，让观众重新注意刚发生的变化。
2. 点出表面反应和真实心理之间的反差，例如“嘴上质疑，却主动靠近”。
3. 自然带出检索到的知识卡或心理学效应，并用卡片支持的因果链解释它如何作用于当前剧情；不要写成“这里运用了某某效应”的教科书解说。
4. 把机制落回男人可理解的表达或推进原则，让观众知道普通做法错在哪里、高段位做法改变了什么。
5. 把需求留给后续 CTA：让观众意识到自己缺的是一种具体表达、判断或推进能力，但不要在转场里再次号召关注、进群、买课或咨询。

优先采用爆款开头系统里的强钩子方式：短问短答、强判断、反常识反差、身份落差、损失提醒或明确结果。它们只用于提高转场力度；第一句必须立刻锚定前面的剧情，不能凭空另起一个无关开头。热门骨架可以改变第一句的功能，但不能脱离刚刚发生的画面。

## 力度标准

- 先说关系变化或现实结果，再解释原因。优先使用“从质疑到主动靠近”“不急着索要答案”“先建立关系预期”这类可感知变化。
- 把机制写具体：她为什么放下防备、为什么产生想象、为什么愿意继续推进，以及男人哪种表达改变了互动。
- 允许使用“关系预期”“男女框架”“心理位置”等术语，但术语必须帮助观众理解当前剧情，不能堆成课程目录。
- 口吻要像成年男性旁白：笃定、克制、有洞察，不油腻，不喊口号，不写论文腔。
- 避免“你看”“其实”“这个片段告诉我们”“真正重要的是”等无力度起手。
- 不把单个剧情夸成对所有女性都必然有效；力度来自清晰判断和画面证据，不来自绝对保证。
- 不把热门开头系统变成固定万能句；批量写作要轮换句式功能和开头骨架，而不是每条都套同一模板。

## 边界

- 不修改用户提供的剧情提示词、角色台词、镜头或表演安排。
- 不续写新的剧情，不替角色补台词，不增加案例或咨询故事。
- 不提前说固定 CTA 的产品、价格、进群方式或行动口令。
- 不重复写一段 CTA，也不把转场收成“所以你要学会”“赶紧点击”等行动指令。
- 不逐句复述剧情。引用一个关键词或一句关键台词后，立即转向心理反差和机制。
- 不为了“狠”而写贬低、羞辱、强迫或虚假必然结果。

## 已验收力度基准

剧情核心：男人把女人备注为“未来女朋友”，女人先质疑，听懂后主动靠近。

检索命中：`B-018` 的“植入人设”知识卡。该卡把标签效应概括为：给对方一个身份标签，对方接受并回应后，会更倾向于往这个标签所指的方向表现。这里使用它解释“未来女朋友”如何先把关系身份放进女方的心理预期；不把靠近写成所有人都会出现的必然反应。

转场：

> 为什么一句“未来女朋友”，就能让女人从质疑变成主动靠近？这背后用的就是心理学上的标签效应。你先把“未来女朋友”这个身份放进她的脑子里，她一旦愿意回应这个标签，就已经开始想象你们成为情侣后的关系。高段位的暧昧，不是追着她要答案，而是先让她在心理上走进这个角色。

这个样稿用于校准节奏和力度。处理新剧情时必须重新提炼其关键反差和心理机制，不得只替换人物、台词或名词。

批量变体示例（同一知识机制，不同热门开头入口）：

- `结果先行`：女人嘴上还在质疑，身体已经先替她做了选择。这里真正起作用的，是标签效应……
- `身份落差`：你以为“未来女朋友”只是句暧昧话，其实它是在提前给关系放一个身份标签……
- `损失提醒`：很多男人一开口就逼女人确认关系，反而把她刚产生的想象逼没了。标签效应真正厉害的地方是……
- `强判断`：女人不是不能接受你表达喜欢，她抗拒的是你立刻向她索要答案。先把身份放进去，才会让她自己开始补全关系……

这些句子只是变体方向，不是新的固定模板；正式批量时必须以当批可访问的用户开头库和实际知识卡为准。

## 输出前检查

- 第一秒能听出它承接的是刚才那段剧情，而不是另一条新文案。
- 已完成知识库检索；选中的卡片或效应同时匹配剧情动作、可见反馈和关系阶段。若未命中，已经如实说明而没有伪造来源。
- 有一个清楚的反差和一个具体机制，没有堆多个论点或心理学名词。
- 批量稿已记录并检查热门开头骨架、句式功能和知识卡组合；相邻稿件没有重复同一套入口。
- 能顺接固定 CTA，但没有提前复述或抢走 CTA。
- 自然口播预计不超过 `25` 秒；有实际 TTS 时已经按音频复核。
- 最终只留下可配音正文，没有解释、提示词痕迹或多余标签。
