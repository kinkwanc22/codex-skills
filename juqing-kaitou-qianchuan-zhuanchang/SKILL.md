# 剧情开头千川续写转场

把短剧情已经制造出的情绪、反差或关系结果，提炼成一段可直接配音的旁白，放在剧情与固定 CTA 之间。转场既要承接观众刚看到的画面，也要为 CTA 打开需求，不能变成剧情复述、普通总结或第二条独立文案。

## 默认交付

- 默认只交付一版完成稿；用户要求对比时再给备选。
- 默认时长 `12-15` 秒，`15` 秒为硬上限。没有实际 TTS 时，按自然口播控制在约 `55-75` 个中文字符，并明确时长是估算；有指定音色或语速时以实际音频为准，超时就压缩。
- 交付可直接用于 TTS，不加标题、序号、舞台提示、引号说明或 CTA 占位符。
- 用户给了固定 CTA 时，先读懂 CTA 的承诺和入口，但不得改写、压缩或提前复述它；用户未给 CTA 时，转场收在“问题机制或能力缺口”上，保留自然接入空间。

## 写法

从剧情中只抓一个最有传播力的瞬间：关键台词、人物态度反转、身体反应或关系推进结果。围绕它完成以下逻辑，不必机械分成四句：

1. 用剧情里的关键台词或可见结果提出一个短而有力的问题，让观众重新注意刚发生的变化。
2. 点出表面反应和真实心理之间的反差，例如“嘴上质疑，却主动靠近”。
3. 用一句明确判断解释真正起作用的关系机制，不泛讲“情商”“技巧”或“会聊天”。
4. 把需求留给后续 CTA：让观众意识到自己缺的是一种具体表达、判断或推进能力，但不要在转场里再次号召关注、进群、买课或咨询。

优先采用爆款开头系统里的强钩子方式：短问短答、强判断、反常识反差、明确结果。它们只用于提高转场力度；第一句必须立刻锚定前面的剧情，不能凭空另起一个无关开头。

## 力度标准

- 先说关系变化或现实结果，再解释原因。优先使用“从质疑到主动靠近”“不急着索要答案”“先建立关系预期”这类可感知变化。
- 把机制写具体：她为什么放下防备、为什么产生想象、为什么愿意继续推进，以及男人哪种表达改变了互动。
- 允许使用“关系预期”“男女框架”“心理位置”等术语，但术语必须帮助观众理解当前剧情，不能堆成课程目录。
- 口吻要像成年男性旁白：笃定、克制、有洞察，不油腻，不喊口号，不写论文腔。
- 避免“你看”“其实”“这个片段告诉我们”“真正重要的是”等无力度起手。
- 不把单个剧情夸成对所有女性都必然有效；力度来自清晰判断和画面证据，不来自绝对保证。

## 边界

- 不修改用户提供的剧情提示词、角色台词、镜头或表演安排。
- 不续写新的剧情，不替角色补台词，不增加案例或咨询故事。
- 不提前说固定 CTA 的产品、价格、进群方式或行动口令。
- 不重复写一段 CTA，也不把转场收成“所以你要学会”“赶紧点击”等行动指令。
- 不逐句复述剧情。引用一个关键词或一句关键台词后，立即转向心理反差和机制。
- 不为了“狠”而写贬低、羞辱、强迫或虚假必然结果。

## 已验收力度基准

剧情核心：男人把女人备注为“未来女朋友”，女人先质疑，听懂后主动靠近。

转场：

> 为什么一句“未来女朋友”，就能让女人从质疑变成主动靠近？因为女人抗拒的不是你表达喜欢，而是你急着向她索要答案。高段位的暧昧，是先给她一个关系预期，再让她自己走进来。

这个样稿用于校准节奏和力度。处理新剧情时必须重新提炼其关键反差和心理机制，不得只替换人物、台词或名词。

## 输出前检查

- 第一秒能听出它承接的是刚才那段剧情，而不是另一条新文案。
- 有一个清楚的反差和一个具体机制，没有堆多个论点。
- 能顺接固定 CTA，但没有提前复述或抢走 CTA。
- 自然口播预计不超过 `15` 秒；有实际 TTS 时已经按音频复核。
- 最终只留下可配音正文，没有解释、提示词痕迹或多余标签。
