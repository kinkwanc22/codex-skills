# 数字人千川

2026-11-05用户要求检查并在没有独立流程时新建。本技能是新生产路线的入口，不是已验收母版；尚无本模式首条样片、固定出场结构或已验证专用构建器。现有数字人自然流/街拍的用户认可不等于本模式已验收。

## 独立边界与首次配置

- 只用于用户明确指定的数字人千川；普通千川不自动加入数字人，数字人自然流不自动追加千川CTA。
- 开始前完整读取[千川双版本标准](../qianchuan-copy-standard/SKILL.md)，锁定过审版或风险版。新批未指定默认过审版并说明；风险版保留其选定旧文案及已识别风险，不默默换成过审稿。
- 先记录文案来源、账号、画幅、数字人身份/造型、数字人出场范围、选用CTA及包装母版。用户已有明确要求就沿用；不要重复提问。尚无本模式锁定结构时，只问会改变付费生成范围的必要问题：数字人全程，还是仅在开头/CTA等指定段落出现；画幅不明确且无来源可判断时一并确认。
- 不把“新建流程”理解为授权立即付费生成样片。当前仅创建skill；后续实际制作请求中再冻结上述配置。不能把未定配置写成用户已验收参数。
- 不自动加入自然流的横版通用片头、竖版齿轮、心跳、正文单图、中段进群CTA。若用户明确选数字人街拍或数字人自然流，应切到对应原技能，而非用本模式覆盖它们。

## 文案与CTA

1. 用户提供完整稿时保留原稿，按所选版本处理；只提供开头且要求续写时，读取[千川开头续写](../qianchuan-hook-continuation/SKILL.md)。自然流轻修转千川走[ziranliu-gai-qianchuan](../ziranliu-gai-qianchuan/SKILL.md)，爆款融合走[baokuan-ronghe-diedai](../baokuan-ronghe-diedai/SKILL.md)，不要混用扩写权限。
2. 原热门完整开头优先保留。过审版只对必要风险词组最小替换；风险版按其旧流程执行。记录源开头和采用开头，不擅自换成数字人自我介绍。
3. 核对正文尾部已有CTA，避免重复。使用当次选定的CTA1、CTA2、CTA1b或CTA2b及其实际确认文本；同时记录文案模式和文本哈希。随机CTA只在用户授权随机时抽取，抽定后重试不再抽。
4. 过审版CTA须符合共享标准，不直接套仍有保证的旧音轨；风险版不能误用过审字幕与旧配音组合。新增或修订CTA与历史正式原件分别保存。
5. 全片实际音频含CTA以298秒为上限；超时报告实测及可压缩正文范围，未经当次授权不删原开头、删CTA、加速或默默重写。

## 配音、字幕与数字人

1. 实际生成语音前读取[xiangongyun-tts](../xiangongyun-tts/SKILL.md)，沿用当次确认音色/实例和原速。需要复用已有音频时逐段核对文本与版本；不是同名文件就可直接复用。
2. 用[srt-aligner](../srt-aligner/SKILL.md)按最终文本语义分行、对齐实际音频，修复漏读误读；先冻结完整主音轨，再划定数字人出场区间。以完整句和实际词时间为边界，不按固定秒数或模板字数猜切点。
3. 从同一最终PCM主音轨精确截取数字人区间，记录音频哈希、起止时码及样本范围。可参考现有数字人横/竖版的prepare_avatar_audio.py，但先检查参数及区间能力；不要未经验证把仅前缀截取脚本用于中段CTA。
4. 实际调用数字人生成前读取当前HeyGen工具的生成要求；仅使用用户授权的身份/造型。Gary造型可参考[横版数字人](../avatar-hengban-ziranliu/SKILL.md)或[竖版数字人](../avatar-shuping-ziranliu/SKILL.md)的对应画幅选型规则，不继承它们的自然流时间线。
5. 用截取音频驱动，不再把文案交给数字人平台重新配音；关闭会改变声音的语音镜像等选项，保留原节奏。每段冻结实际look ID、画幅、分辨率、用户选定模型及任务ID。所选模型与返回任务标签冲突时如实记录，不冒充核实；模型不可用不静默替换。
6. 未知结果先查询原任务，不盲目重复付费提交。下载后核对实际文件可读、画幅、时长、完整口播、音画对应及口型；每段独立测量偏移，不沿用历史样本23ms常数。不能用冻结、循环或变速掩盖缺失口播。

## 剪映草稿与包装

- 先保存`manifest`：源文/采用文本、模式、CTA、主音频/SRT、数字人区间、look与任务ID、实际视频、补充镜头、模板来源、未解决问题。长任务同步维护工作目录CURRENT_CONTEXT.md或STATUS.md。
- 生成新的数字人千川草稿，不覆盖旧数字人/自然流/千川稿。名称包含`数字人千川｜横屏或竖屏｜主题｜CTA编号｜过审版或风险版｜日期`；补充女主素材时另记实际女主编号，不给数字人冒用女主编号。
- 保留同一主配音贯穿，数字人视频及其他视频的自带声音全部静音；视觉放覆盖轨，主视频轨空置。字幕按同一主音频时间轴，不重复添加数字人平台导出字幕。
- 包装只能继承当次明确选择的千川母版。选择街拍/横屏自然流包装时读[jiepai-jianji](../jiepai-jianji/SKILL.md)相应分支；选择竖屏自然流千川CTA包装时读[shuping-qianchuan](../shuping-qianchuan/SKILL.md)及其CTA母版参考。不得把继承字体/音量误解为必须保留该模式的全套视觉结构。
- 首次未选母版时先确定包装方案再组装，不凭空宣称已有固定字体、位置和特效；经用户校准的参数才能保存为本模式专用母版。过审版复核所有标题、贴纸、画中画、CTA背景，不以“固定预设”为免检理由。
- 非数字人区间仅在已选结构确实需要时补充素材，按语义情绪匹配和该模式去重规则处理，不自行扩大素材库或插入女性展示镜头。
- 默认后台制作，不抢占前台。前台验收需当次允许；未实际打开播放，只报告后台文件检查，不能宣称完整播放或平台通过。已打开升级的旧稿不后台原地重建。

## 交付与校准

交付剪映草稿及清单，区分文稿冻结、配音字幕、数字人提交/生成/下载、资源参数检查、首页注册分类、实际打开播放、导出与投放各状态。创建草稿不自动授权上传发布，也不以MP4替代草稿。

检查完整音轨、字幕、数字人口型与CTA一致，接缝无漏字/重复/黑帧/停顿，总长实测≤298秒，视频静音与主轨要求正确。首条样片尚未由用户验收时明确标记“试制”；用户确认后仅保存其实际调整的出场范围、字体位置、包装参数和母版来源，不修改另外三种数字人流程的默认规则。
