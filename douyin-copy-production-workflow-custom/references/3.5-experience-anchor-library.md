# 3.5 Experience-Anchor Library

Read this file during 3.5 frozen-source design when an article benefits from a concise Gary experience anchor.

## Approved Anchors

- `EA-001`：`上周咨询的一个兄弟，我们叫他XX，他就是典型的XX。`
- `EA-002`：`在我负责过的海量咨询案例中，其实大部分男人在XX 时都会XX，这是很正常的现象。`
- `EA-003`：`我在群里帮兄弟们复盘案例的时候，经常会发现一个问题，`

The three approved expressions above are wording-locked. Preserve them exactly; only replace the `XX` slots with topic-matched content supported by the source, the selected knowledge record, or a confirmed Gary case record. Do not silently polish, paraphrase, or standardize the approved wording.

## Use Contract

- This is an optional expression library, not a quota. Select an anchor only when it naturally strengthens the current argument.
- Do not insert all approved anchors into every manuscript. Repeated visible use across adjacent points or manuscripts is a homogeneity defect.
- Codex selects and fills the appropriate anchor while designing the frozen source. Only that completed sentence enters the frozen source.
- Never append this entire library, its IDs, or its instructions to the Gemini request. Gemini still receives only the complete old 2.5 prompt, the builder-owned 3.5 locks, and the frozen source.
- An experience anchor is not automatically a full student case. If the surrounding passage claims a concrete consultation result, it must also satisfy the 3.5 Student Mini-Case Contract.
- Record every adopted anchor ID in `experience_anchor_ids`. Record an empty list when none is used.
- New candidate wording enters this approved section only after the user explicitly approves it.
