# 探花Gary 3.5热门开头系统V3

## 核心变化

V3不再先按题目相似度套用开头。先从成稿提取三张可独立排列的卡片，再根据最强欲望刺激决定首句：

- **W（Weakness/Want）**：女人的弱点、欲望、本能、矛盾、选择漏洞，或男人正在承受的直接痛点。
- **K（Key）**：`只要 / 记住 / 掌握 / 看懂`加有限数量的话术、步骤、开关、规则或操作，让复杂结果显得简单可得。
- **R（Reward）**：先把正文中的具体反馈压缩成一个男人会自然说出口的刺激结果，例如`让她为你失守`或`拿到她身心的入口`。不得在开头罗列回复、暴露、暗号、改期等正文证据。

三张卡可以使用任意排列：`W-K-R`、`W-R-K`、`K-W-R`、`K-R-W`、`R-W-K`、`R-K-W`。女人弱点最猎奇就W先行，结果最诱人就R先行，方法最简单具体就K先行。开头总共最多两句话；`今天我们要聊的是`可以并入第二句话，不再强制单独占一句。

## 匹配顺序

1. 提取正文中真实存在的具体反馈和结果证据。
2. 按`具体行为 -> 隐藏变化 -> 男性幻想 -> 自然口语结果`逐层压缩，得到一个R；不能跳过中间层直接生造课程名词。
3. 提取最有刺激性的女人弱点或男人痛点，再提取有限、低门槛、可收藏的K。
4. 从V1库按“欲望引擎 + 结果形状”寻找来源；题目相似度只用于同分决胜。
5. 决定W/K/R排列，并把最强刺激放进第一句话，把最强结果放在整段最后。
6. 最后检查数字、报题和正文因果接口；同母题A/B对比必须使用同一个开头。

## 欲望引擎

- **女性弱点型**：欲望、生理本能、潜意识测试、低价值排斥、不配得感。
- **捷径结果型**：几句话、几步、几个开关，把冷淡、没话题、邀约失败直接改成主动反馈。
- **高价值猎物型**：美女、顶尖女性、难搞对象，配合反常识降难度与征服结果。
- **反派秘密型**：渣男、海王或强势男人掌握的阴暗机制，满足翻盘、报复和反向投入。

## 用词选择

当前Gary短期开头必须在两句话内同时产生好奇、色欲、阴暗、懒惰和掌控感，其中一种可以最强；低俗双关按题目选用。验收看整体感受，不按字面凑词：

- 好奇：`隐秘 / 不会承认 / 真正秘密 / 潜意识 / 另一面 / 底层开关`
- 色欲：`生理欲望 / 本能反应 / 身体诚实 / 无法抵抗 / 欲望名单 / 上头`
- 阴暗：`弱点 / 漏洞 / 筛选机制 / 黑暗规则 / 隐形权力 / 欲望操盘`
- 懒惰：`只要 / 记住几句 / 三个步骤 / 一个动作 / 最短时间 / 直接跳过`
- 低俗双关：`进入她 / 打开开关 / 给你留门 / 贴上来 / 嘴上拒绝身体诚实`。保持暧昧和秒懂，不写成露骨描写。
- 掌控与地位：`跟随节奏 / 交出推进权 / 围绕你运转 / 主动补位 / 反过来追你 / 从被动挨打到掌控`

可观察动词`主动靠近 / 主动延长 / 主动回流 / 主动投入 / 主动制造下一次机会 / 从冷淡变主动 / 反过来推进关系`只作为正文兑现证据，开头要继续压缩为`让她为你失守 / 让她不想再装 / 拿到她身心的入口`一类自然结果。`看懂女性心理 / 提升男女认知 / 改善相处模式 / 学会正确表达 / 理解底层逻辑`不能单独承担诱惑承诺。

## 验收

1. 总共最多两句话，建议80-130个中文字符；第一句制造黑暗判断或身份冲突，第二句可以合并报题、有限K和终极R。
2. 好奇、色欲、阴暗、懒惰和掌控五种感受必须同时成立，但不得靠堆关键词完成。
3. 每个开头最多保留一个高刺激包装词，其他部分用自然口语；连续出现`系统、机制、层级、准入权、分配权`等课程目录式复合词，直接退回。
4. 不罗列正文证据，不使用完整场景或具体实物比喻；`入口、开关、防线、主导权`等自然抽象词可以使用。
5. 最强结果必须落在整段最后。删掉最后十个字后如果刺激没有明显下降，说明结果位置不合格。
6. 数字必须与正文一致。正文通过具体证据语义兑现抽象奖励，但不得把一次主动反馈夸成绝对服从、永久占有或彻底控制。
7. 进行口语反AI检查：男人私下不会对兄弟说的课程词，优先改成动作。能写`绕过她的理性`，就不写`突破女性理性防御机制`。
8. 拒绝正文摘要式、解释式和防御式起手。相邻稿件轮换黑暗判断、身份落差、隐秘规则、代价警告、终极奖励等句子功能，不靠降低刺激避免重复。
9. 同母题A/B测试共用一个开头，避免开头成为额外变量。
10. 运行记录保存V1来源、W/K/R原卡、证据压缩链、排列、五种刺激覆盖、唯一包装词、评分、改写理由和最终指纹；Word只展示最终开头。
