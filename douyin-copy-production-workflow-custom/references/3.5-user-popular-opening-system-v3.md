# 探花Gary 3.5热门开头系统V3

## 核心变化

V3不再先按题目相似度套用开头。先从成稿提取三张可独立排列的卡片，再根据最强欲望刺激决定首句：

- **W（Weakness/Want）**：女人的弱点、欲望、本能、矛盾、选择漏洞，或男人正在承受的直接痛点。
- **K（Key）**：`只要 / 记住 / 掌握 / 看懂`加有限数量的话术、步骤、开关、规则或操作，让复杂结果显得简单可得。
- **R（Reward）**：击中男人好奇、色欲、阴暗心理、懒惰、征服欲、掌控欲、地位欲或低俗双关兴趣的具体结果。

三张卡可以使用任意排列：`W-K-R`、`W-R-K`、`K-W-R`、`K-R-W`、`R-W-K`、`R-K-W`。女人弱点最猎奇就W先行，结果最诱人就R先行，方法最简单具体就K先行。`今天我们要聊的是`属于后置报题，不属于三张卡。

## 匹配顺序

1. 锁定正文实际能够兑现的男性欲望终点。
2. 提取最有刺激性的女人弱点或男人痛点。
3. 提取有限、低门槛、可收藏的钥匙。
4. 从V1库按“欲望引擎 + 结果形状”寻找来源；题目相似度只用于同分决胜。
5. 决定W/K/R排列，并把最强卡放到前20个汉字。
6. 最后补数字报题和正文真实的因果接口。

## 欲望引擎

- **女性弱点型**：欲望、生理本能、潜意识测试、低价值排斥、不配得感。
- **捷径结果型**：几句话、几步、几个开关，把冷淡、没话题、邀约失败直接改成主动反馈。
- **高价值猎物型**：美女、顶尖女性、难搞对象，配合反常识降难度与征服结果。
- **反派秘密型**：渣男、海王或强势男人掌握的阴暗机制，满足翻盘、报复和反向投入。
- **权力跃迁型**：黑暗规则、人性定价、阶级跨越、关系主导权、情感与事业双重结果。

## 用词选择

每篇选一个主刺激，通常再配一个副刺激：

- 好奇：`隐秘 / 不会承认 / 真正秘密 / 潜意识 / 另一面 / 底层开关`
- 色欲：`生理欲望 / 本能反应 / 身体诚实 / 无法抵抗 / 欲望名单 / 上头`
- 阴暗：`弱点 / 漏洞 / 筛选机制 / 黑暗规则 / 隐形权力 / 欲望操盘`
- 懒惰：`只要 / 记住几句 / 三个步骤 / 一个动作 / 最短时间 / 直接跳过`
- 低俗双关：`进入她 / 打开开关 / 给你留门 / 贴上来 / 嘴上拒绝身体诚实`。保持暧昧和秒懂，不写成露骨描写。
- 掌控与地位：`跟随节奏 / 交出推进权 / 围绕你运转 / 主动补位 / 反过来追你 / 从被动挨打到掌控`

结果优先使用可观察动词：`主动靠近 / 主动延长 / 主动回流 / 主动投入 / 主动制造下一次机会 / 从冷淡变主动 / 反过来推进关系`。`看懂女性心理 / 提升男女认知 / 改善相处模式 / 学会正确表达 / 理解底层逻辑`不能单独承担诱惑承诺。

## 验收

1. 前20个汉字至少触发好奇、色欲、阴暗、懒惰、低俗双关、掌控、地位冲突或风险中的一种。
2. 报题前至少出现两种兼容刺激，并包含K或R之一。
3. 报题前通常只写两到三个短分句，不写成长篇理论说明。
4. 抽象感来自少量高压名词，不来自连续解释。
5. 数字、机制和结果必须与正文一致；正文前部必须接得住开头承诺。
6. 相邻稿件轮换主刺激、排列、钥匙名词和结果动词，禁止只换题目与数量。
7. 运行记录保存V1来源、W/K/R原卡、排列、主副刺激、评分、改写理由和最终指纹；Word只展示最终开头。
