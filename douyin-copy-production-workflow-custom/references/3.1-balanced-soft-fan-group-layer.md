# 3.1 Balanced Soft Fan-Group Layer

Read this file after a 3.1 Gemini body passes topic, count, force, and length checks and before title/opening packaging or Word export.

## Purpose

The user's conversion path is:

`video traffic -> follow -> Douyin fan group -> private-domain conversion`

The 3.1 manuscript must remain a valuable traffic manuscript first. The fan-group layer should make Gary's real diagnostic and review capability repeatedly visible without turning the body into a long CTA. This is a narrow Codex post-generation edit. It does not change the knowledge route, mother topic, promised count, Gary force band, or old-2.5 expansion style.

## Default Transformation

Unless the user explicitly requests another CTA treatment:

1. Keep the complete standard 2.5 prompt unchanged for Gemini.
2. After generation, remove the large explicit mid-article CTA produced by that prompt.
3. Remove the large dynamic ending CTA produced by that prompt.
4. Preserve the exact final sentence: `我是探花Gary，我们粉丝群里见，感谢观看`.
5. Add balanced, article-native soft placements inside the body.

Do not send this layer back to Gemini. Codex performs it after the body is accepted.

## Density

Choose density from the accepted body length, not from a fixed paragraph count:

- Target roughly one soft placement per 600-800 Chinese characters.
- A body around 4000 CJK normally receives 6 placements.
- A body around 6000 CJK normally receives 8-9 placements.
- A body around 8000 CJK normally receives 9-10 placements.
- Do not exceed 10 without explicit user instruction.

For the approved 6095-CJK calibration manuscript, the accepted target is 9 placements.

## Placement Mix

For a 6000-CJK manuscript with 9 placements:

- 3-4 may explicitly use `粉丝群` or `群里`.
- The remainder should show Gary's diagnostic ability, review method, pattern recognition, or the gap between knowing a theory and locating one's own failure.
- None should directly instruct the viewer to `进群`, `关注`, `去主页`, `加入`, `私信`, or contact private domain unless the user explicitly asks for a light or direct CTA tier.

Vary the carrier across the manuscript:

- real-interaction review habit;
- diagnostic question or distinction;
- timeline or behavior-chain method;
- common failure pattern seen in submitted interactions;
- occasional fan-group discussion context.

Do not make every placement say `粉丝群里……`, `我在群里……`, `我平时拆……`, or `复盘时……`. Repeating one carrier creates a new advertising template even when each sentence is short.

## Integration

- Write every placement from the current paragraph's mechanism, scene, and judgment. Generic group copy is a failure.
- Mix paragraph-middle, paragraph-end, and transition positions. Do not always append a standalone paragraph after a list item.
- Keep each placement to one natural sentence. It should sound like a continuation of Gary's current explanation.
- A placement may demonstrate expertise or reveal an individual diagnostic gap, but it may not fabricate a named student, result, screenshot, volume claim, or verified group event.
- Do not add a new mechanism, case, operation, conclusion, or promised result. This layer changes conversion visibility only.
- Do not soften, professionalize, or add defensive language around the original claim.

## Production And Review Output

- Production Word: no yellow highlight, comments, risk notes, or backstage label.
- Review/comparison Word: when the user explicitly asks to inspect new soft placements, highlight only the inserted text in yellow. Preserve the clean production draft separately.
- Never overwrite the clean accepted manuscript while testing placement variants.

## Acceptance Gate

Before export, record and verify:

- `soft_layer_applied: true`
- `body_cjk`
- `soft_placement_count`
- `average_soft_gap_cjk`
- `explicit_fan_group_placement_count`
- `direct_action_placement_count: 0` by default
- `large_mid_cta_removed: true`
- `large_end_cta_removed: true`
- `fixed_ending_preserved: true`
- `yellow_review_only: true|false`

Reject and revise when:

- the body still contains a large promotional block before the fixed ending;
- more than half of the placements explicitly mention the group;
- the same self-reference carrier repeats mechanically;
- the placement can be pasted into an unrelated article unchanged;
- the insertion interrupts the argument, changes the mother topic, or introduces a new claim;
- the clean production Word contains yellow highlighting;
- a test Word overwrites the clean accepted draft.
