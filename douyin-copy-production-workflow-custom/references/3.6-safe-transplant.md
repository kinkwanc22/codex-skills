# 3.6 Safe Transplant Expansion

Read this file in full when the user asks for `3.6`, `3.6安全版`, `安全换新扩写`, or asks to run the 3.5 replacement mechanism before 2.8 expansion.

## Canonical Meaning

3.6 is:

`3.5 pre-expansion transplant design -> frozen new route -> complete 2.8 Safe Draft expansion -> 3.6 acceptance and duplication review`

It is not a softened 3.5 result and not an ordinary 2.8 expansion of the source manuscript. The replacement happens before Gemini. The complete 2.8 prompt expands only the already-frozen new route.

## Inherited From 3.5

Before Gemini, follow `3.5-codex-first-knowledge-supported.md` through the end of the lean frozen-source stage:

- lock the exact body-derived public mother topic, audience promise, relationship stage, desired result, and attack direction;
- treat the source count as reference evidence; the selected final count may stay equal, decrease, or increase when the new same-level hierarchy is stronger;
- search the complete same-mother-topic lineage across every status and exclude its public point hierarchies and dominant causal routes;
- create and score three materially different topic-native routes locally, without three Gemini generations;
- pass the direct-answer, promise-delivery, native-title, no-new-umbrella, relationship-account relevance, causal-order, and expansion-capacity gates;
- build and validate `old_25_engine_plan.json` so the route has one master memory spine, causal acts, governing judgments, rotated proof carriers, escalation, and a position or identity shift;
- retrieve knowledge only to support the chosen route, not to rename or determine the public skeleton;
- freeze one lean route skeleton below the 3.5 adaptive limit, including the selected count and fixed ending;
- register the route immediately so later same-topic versions cannot reuse it.

The 3.5 lineage exclusion applies across 3.1, 3.3, 3.5, 3.6, transplant, rejected, pending, exported, and published artifacts that answer the same mother topic. Familiar mechanisms used only under unrelated mother topics may be rebuilt for the new topic. Never claim that these checks guarantee an undisclosed platform result.

## 2.8 Expansion Contract

Build the request only with `scripts/build_36_gemini_prompt.py`. It combines:

1. the complete `2.8 Safe Draft / 安全版` block from `gemini-expansion.md`;
2. a fixed 3.6 exact-mother-topic, selected-count, content-line, and no-new-umbrella lock;
3. the validated 3.5-style `old_25_engine_plan.json` boundary check;
4. the lean frozen replacement source.

Run the prompt with `--session 3.6`. The dedicated session keeps 3.6 tests and accepted turns separate from ordinary 2.8 and from 3.5's hard-edged voice memory. Never use the mixed default session. Use `--isolated` only for an explicitly requested clean comparison, not routine production.

The complete 2.8 prompt controls the language surface: natural Gary narration, hidden six-layer development, fewer empty intensifiers, safer terminology, TTS-ready sentences, one natural mid-body fan-group conversion, a closing conversion, and the fixed ending. The 3.6 lock controls the immutable topic, selected count, route boundary, and relationship-account relevance. When they appear to conflict, preserve the exact mother topic and selected route while expressing them in the safer 2.8 vocabulary; do not replace the source's reader promise with a neutral education topic.

The final body must satisfy the strictest active 2.8 length requirement: at least 4300 Chinese characters, normally 4800-5600. It must deliver every selected public point and end exactly with `我是探花Gary，我们粉丝群里见，感谢观看。`

## Cases And Claims

Cases are optional. If the frozen source contains `此处植入案例。`, Gemini may create a compact illustrative case, but the public manuscript must not present invented identities, volumes, screenshots, exact money, guaranteed outcomes, or independently verified facts. A user-confirmed Gary consultation case may be described as a real consultation only within the confirmed evidence boundary. Otherwise use ordinary scenario language or clearly non-documentary composite narration.

Do not force one consultation case into every article. Safety does not authorize generic filler or a detached success story.

## Acceptance

After expansion:

- save the raw output unchanged;
- permit only narrow grammar, punctuation, broken-word, TTS, fixed-ending, and clearly unsupported precision repairs;
- rerun from the same frozen route for underlength, truncation, missing promised points, topic drift, a new umbrella topic, failed relationship-account relevance, or missing causal structure;
- repeat the title-hidden mother-topic-native audit;
- compare the complete final text against the source and discoverable Gary history; reject substantial copied passages or an earlier public point chain, but do not reject common concepts or short generic phrases;
- keep the status `generated / 正文待确认` until the user approves the writing quality.

Use the normal non-3.5 Word package unless the user specifies a different delivery layout. Label every run and filename as `3.6`; do not call it 3.5, 2.8, or 3.1H.
