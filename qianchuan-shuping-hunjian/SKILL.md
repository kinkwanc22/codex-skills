# 千川竖屏混剪

1. 冻结实际口播和字幕，核对用词及句界。已配音的内容剪辑测试沿用指定成稿、CTA和声音；新制作或改写先读[千川文案统一尺度](../qianchuan-copy-standard/SKILL.md)，按用户选定模式处理。不得为了选款改变文案或擅自更换CTA。
2. 新建 9:16 剪映草稿。逐句按语义选竖屏真人镜头，优先动作、表情和构图贴合；画面随字幕断句切换，素材按原速裁切。保留口播、独立配乐、同步英文；沿用验收参考的短叠化及包装。样本不规定文案时长、片段数量或固定镜头。普通竖屏混剪的真人取材规则可参考[竖屏混剪](../shuping-bendi-hunjian/SKILL.md)。
3. 中文逐句套[原预设清单](references/presets.md)：按文义、真人镜头主体、句长和读完所需时间选款，相邻换款，间隔几句可重复，不机械轮转。先在预设原有文字槽里自然断句；长句用放得下的双行或多行，窄槽只给短词。看脸和手部是否被遮，核对换行、字边距、英文避让和动画结束前的可读时间。
4. 对原预设只换文字与时间，保持原字体、配色、排版、遮罩、关键帧和动画。正式候选排除「切割文字」系列（含换字体版及同款别名）和独立「渐显」预设；原有保留款内部的动画不拆换。新增款保持“候选”状态直至用户验收；优先拓展版式和字重而非只有入场差异。资料不齐的预设不硬套，不拿系统字体替代；原示例音效缺失时沿用主稿口播和配乐。
5. 以新名称、新目录和唯一 ID 写入完整副本。复用脚本和素材路径见[制作参考](references/build.md)。验证 33 句样片规则可推广到任意实际行数：字幕与镜头时间对齐、相邻换款、字幕无遗漏、资源路径真实可读。检查嵌套组合及富文本内的字体、字效和资源引用。
6. 必须在剪映打开交付的那份草稿并抽查，尤其开头、新款、最长句和尾段。按[图层与手工编辑](references/build.md#图层与手工编辑)核对叠放和可编辑性；任何后续写入都要重新打开验证。源工程、确认稿及旧试样保留。默认交付草稿，不导出。未在前台验证要明确说明。
