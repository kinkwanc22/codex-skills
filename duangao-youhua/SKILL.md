# 短稿优化

用户于2026-11-10确认的模式：**直接用原文，只改错别字和表达不通畅的地方，不改观点，不另写句子。** 常用于500字以下原稿，但不以字数为强制适用门槛。

## 修改边界

- 原文是唯一底稿。保留完整开头、句式、论点、信息顺序、段落、因果、立场和口播力度；不是只保留大意后重新组织语言。
- 只修明显错字、代词指向、标点、重复或漏字、明确转写错误，以及导致读不通的局部语序和连接。正常句子原样保留，不为“更漂亮”换词。
- 不扩写、不补机制或例子、不新增总结、不改变分项数量，不把短稿扩成完整广告。即使只有几十字，也不凑篇幅。
- 不因自己不赞同原观点而修改结论或论证，不自动加入“通常、可能、也要看”等限定词，也不把原判断改为另一套价值建议。用户另行要求风险修改时才单独处理。
- 若原观点存在绝对化、事实或投放风险，必要时在稿外简短说明；不能把校对稿称为事实核实稿或合规保证。不能借“保留观点”新增歧视、操控、虚构案例或效果承诺。
- 转写不明确时先查上下文及可访问源媒体，不把新TTS当核听证据。无法唯一恢复的核心词不随意猜；保留并在稿外指出，或给最小候选。语境恢复不冒称已核听。

## 执行与交付

1. 读取用户指定的完整原文，区分文件标题、标签、点赞数据与实际正文。保留源文件，不覆盖。
2. 逐句最小校对；每一处改动都应能回答“原文哪里不通或写错了”。没有明确问题就不改。
3. 与原文逐句对照，确认没有新观点、删掉的论证、重排的句子或额外收尾。对不确定转写说明依据。
4. 默认直接贴出干净正文；只有必要疑点或用户要求时另附简短修改记录。说明不能混入配音正文。

本技能只处理文字。用户明确要求接CTA时，再读取实际确认的CTA全文并单独匹配，不从记忆重构或擅改正式版本；默认不自动附CTA。要求继续制作时再调用对应配音、字幕和剪辑skill，区分正文风险、实际音频时长和平台审核状态。不自动付费生成、删旧稿、投放或上传。

## 接千川CTA时的一句转场

用户补充：短稿接千川CTA时，在正文与固定CTA之间加**一句**转场。这是正文之外单独新增的承接，不扩大正文修改权限；用户要求不接CTA时也不自动加转场。

- 先读正文结尾和实际采用CTA的开头，按当篇主题写一句自然、直接、有力度的承接，不机械套用统一句子。
- 不另加总结段，不扩成长过桥或第二套CTA，不重复固定CTA已说的课程介绍、点击指令或开头问句。
- 收获落在课程实际讲解的判断、表达与互动方法，不新增保证课程效果、改变对方意愿、虚构反馈或个体结果。
- 保留“正文／一句转场／固定CTA”三个独立部分；正文继续最小校对，固定CTA全文不擅改。检查接起来不突兀、无重复引流，冻结后再配音。

## 本次校准

- “表现的身份温柔”→“表现得十分温柔”：错字及语法修复，允许。
- “就靠着强势拿捏。对方就逼着男人，顺着自己”→“就靠着强势拿捏对方，逼着男人顺着自己”：误断句修复，允许。
- 把“她一定……”改成“她通常……也要看……”：改变判断，不属于短稿优化。
- 将原文整段改为“你要建立边界、提升自己”的新结论：改变框架与观点，不允许。

以上仅校准改动幅度，不把原稿的两性判断当作已验证事实或后续统一写作模板。
