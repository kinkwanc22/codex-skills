# 竖版自然流规则

当前标准版本：2026-09-18 第四版校正。

当前标准母版：`竖屏自然流_B03_第四版规则校正测试`。

人工校准参考：`竖屏自然流_B02_Mac后台结构测试`。

## 一、时间线结构

1. 画幅固定为 9:16。
2. 主视频轨保持空置。人物视频和正文图片全部放在附加画面轨（`flag:2`）。
3. 开场和正文的分界必须按文案语义判断，不复制固定秒数。一般以“今天我们要聊的是”或同等开场语的最后一条字幕结束点作为开场口播结束点。
4. 开场口播结束后插入 1.833333 秒齿轮声。正文真正开始点等于开场口播结束点加齿轮声时长。
5. 正文口播、心跳声、正文中英文字幕、正文标题、正文小标题和正文图片必须在正文开始点同步出现。

## 二、画面衔接

1. 开场允许使用多段人物视频，按本篇开场实际长度分配，不固定照搬 B02 或 B03 的切点。
2. 齿轮声期间继续播放最后一条开场人物视频，不得提前切换正文图片。
3. 齿轮声结束、正文口播开始时，才切换正文单图。
4. 正文只使用一张图片并持续至结尾。
5. 所有画面素材边界统一使用 1 秒“泡泡模糊”转场，包括第一条开场视频到第二条开场视频，以及最后一条开场视频到正文图片。
6. 每一个画面切点必须使用独立的“泡泡模糊”转场材料，不能让两个切点共用同一个转场对象。
7. 每篇尽量使用不同人物和不同素材排列，避免草稿之间视觉重复。

## 三、字幕

### 开场中文字幕

- 字体：研宋体。
- 剪映字号：默认 9 号；短单行字幕且画面不拥挤时允许 10 号。
- 坐标：`(0, 0)`。
- 居中。
- 白色，100% 不透明。
- 必须关闭描边，必须开启阴影。
- 后台生成时，阴影必须同时写入字幕材料外层参数和富文本样式内部的 `shadows` 数组；只写外层 `has_shadow` 不算完成，必须以剪映界面实际显示阴影参数为准。
- 开场不生成英文字幕。

### 正文中文字幕

- 字体：系统字体。
- 剪映字号：8 号。
- 坐标：`(0, -0.24)`。
- 居中、白色、黑色描边。
- 固定放在英文字幕上方。

### 正文英文字幕

- 优先使用剪映翻译；允许外部翻译逐条写入，但必须与中文字幕时间码一一对应。
- 字体：系统字体。
- 剪映字号：8 号。
- 坐标：`(0, -0.35)`。
- 居中、白色、黑色描边。
- 固定放在中文字幕下方，不按画面内容自动移动。

## 四、声音

1. 开场口播和正文口播在语义分界点拆成两段，两段音量均为 `+10 dB`。
2. 开场口播结束后播放齿轮声；齿轮声结束点严格对齐正文开始点。
3. 心跳声严格与正文口播同点开始。
4. 固定背景音乐使用“我的预设7”，从 0 秒开始，音量 0 dB，淡入淡出均为 0。
5. 背景音乐和所有其他层必须裁到本篇实际成片结束点，不保留超长尾段。

## 五、固定包装

- 黑曜滤镜。
- 固定暗角。
- “秘”字马赛克贴纸。
- 正文大标题和“完整未删减版”等包装层从正文开始点出现。
- 标题文字按本篇主题替换，位置和样式沿用标准母版。

## 六、验收检查

1. 开场文字不得透明或半透明。
2. 齿轮声期间仍应看到最后一条开场人物视频。
3. 正文图片不得在齿轮声开始时提前出现。
4. 正文开始时，图片、口播、心跳、标题和中英文字幕必须同步。
5. 正文中文在上、英文在下，位置与标准母版一致。
6. 主视频轨必须为空；实际画面只能在附加轨。
7. 不得存在离线素材、黑帧、尾部空白或超出口播的音乐。

## 七、当前标准的来源

- B02 用于人工校准位置、声音衔接和包装关系。
- B03 第四版用于之后的实际后台生成标准；它已通过结构检查、剪映正常打开和用户画面验收。
- 前三版 B03 只作为错误对照，不得继续复制其透明度、提前切图或错误字幕坐标。
