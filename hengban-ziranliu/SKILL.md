# 横版自然流

## 目标

把已有音频与字幕的剪映草稿制作成 16:9 横版自然流成片。以用户确认的 B05 测试稿为基准，优先复用固定片头成片，避免使用容易黑屏的剪映组合预设或子草稿。

## 固定资源

- 横版通用片头：`/Users/kin/横版通用片头.mp4`
- 片头规格：1920×1080、10.833333 秒、60fps。
- 接入草稿时复制到目标草稿自己的 `Resources` 目录，视频轨静音。
- 不再直接嵌套“我的预设17”组合预设；使用上述已经烘焙完成的普通 MP4。
- 如果固定资源不存在、无法读取或画幅不是横版，停止修改并报告，不得用黑场或其他素材替代。

## 固定画面结构

按文案语义确定时间点，不使用固定秒数套到其他文稿：

1. 从 0 秒开始使用同一位女主的人物视频。
2. 找到“今天我们要讲的是”“今天我们要聊的是”或同义句；在该句结束时切入横版通用片头。
3. 找到结果承诺结束位置，例如“让你在最短时间内……”“让你最短时间提升……”；在该句结束时结束通用片头。按实际区间裁切片头，不变速。
4. 通用片头结束后切回人物视频。
5. 从“另外说一下”字幕开始，切换为同一位女主的一张横版单图，并保持到整条视频结束。
6. 正文包装的四层文字与黄色小图标也从“另外说一下”开始，必须与单图起点完全一致。

开头人物视频、片头前后的人物视频和正文单图必须来自同一个女主文件夹，不得混用人物身份。所有视频保持正常速度并静音。

## 批量差异化规则

制作两个或更多横版自然流草稿时，必须在写入任何草稿前统一分配人物和素材，维护一份批次使用记录，不能逐条独立随机后再碰运气去重。

- 第一优先级：每个草稿使用不同的女主人物文件夹。只要可用人物数量足够，就不允许两个草稿使用同一人物。
- 只有可用人物不足时才允许复用人物；复用前先确认没有仍未使用且素材规格合格的女主人物。
- 即使复用同一人物，该人物视频在时间线上的排列顺序也不能与批次内任何其他草稿相同。
- 不仅要避免“完整顺序完全一致”，开头第一条人物视频也应优先不同；有足够素材时同时更换部分具体视频或使用不同的安全片段，不能只把同一组素材机械轮换位置。
- 从“另外说一下”开始长期显示的正文单图，每个草稿必须使用不同的图片文件；同一人物被复用时尤其不得复用同一张正文单图。
- 横版通用片头是固定公共资源，不计入人物视频和正文单图的重复判断。
- 为每个草稿记录：人物文件夹、人物视频顺序、各视频源路径、正文单图路径。写入前计算人物、视频顺序和正文单图是否与本批次已有草稿冲突。
- 如果素材池不足以满足“不同人物、不同视频排列、不同正文单图”，停止继续生成并明确报告缺少哪一类素材，不得静默重复。

批量验收时至少确认：每个草稿的人物分配优先唯一、所有人物视频序列签名唯一、所有正文单图路径唯一。

## 字幕

横版自然流专用设置如下，并覆盖其他剪辑技能中的字号默认值：

- 字体：Aa研宋。
- 字号：6。
- 阴影：打开。
- 描边：关闭。
- 保留字幕原有时间轴和文字，不改写、不合并、不拆分。

## 开头半透明标题

- 内容：`探花社交`、当前主题完整剖析、`完整未删减版`，保持三行左对齐。
- 从 0 秒开始，持续到“另外说一下”开始。
- 位于画面的最左上角，贴近画布左边缘和上边缘，不保留模板内缩。
- 已确认的剪映归一化位置：`transform.x = -0.548`，`transform.y = 0.82`。
- 保持原模板字体、字号和半透明效果；当前确认透明度约为 `0.3647629310344827`。
- 不遮挡中央字幕，不随着人物视频或通用片头切换而移动。

## 轨道和转场

- 画布为 1920×1080、16:9。
- 主视频轨保持空置；人物视频、通用片头和正文单图全部放在附加画中画轨道。
- 每个画面边界使用剪映原生“叠化”，时长 0.3 秒。
- 所有视频素材音量为 0；只保留配音和明确指定的背景音乐。
- 保留固定免责声明与正文包装，不改变已确认文字内容。

## 素材栏同步

- 时间线实际使用过的全部横版人物视频、横版通用片头和正文横版单图，必须同时导入当前剪映草稿左上角的“素材”栏，不能只在 `draft_content.json` 的时间线上引用文件路径。
- 素材栏只导入本草稿实际使用的源文件，不把同一人物文件夹内未使用的候选素材批量塞入。
- 同一个源文件只在素材栏出现一次；时间线重复使用不重复导入。
- 素材栏中的视频与图片必须仍可读取，名称应能对应到时间线源文件；不得用代理图、封面截图或临时转码文件代替原始人物素材。固定横版通用片头可以使用已复制到草稿 `Resources` 目录的本地副本。
- 为每个草稿记录 `media_bin_sources` 和 `media_bin_count`：内容至少覆盖人物视频列表、通用片头以及正文单图，并与实际使用源文件去重后完全一致。
- 如果通过脚本写入时间线，完成后仍要在剪映前台执行一次批量导入，并目视确认素材栏出现了对应缩略图；仅在 JSON 中存在 `materials.videos` 记录不算完成。

## 检查要求

结构检查后还必须在剪映前台查看：

- 0 秒：人物视频正常，半透明标题在绝对左上角，字幕清楚。
- 通用片头中段：有完整拼贴和品牌文字，不是黑屏。
- 结果承诺结束点：能正常从通用片头切回人物视频。
- “另外说一下”：人物视频结束，单图和正文包装同时开始。
- 素材栏：所有实际使用的人物视频、横版通用片头和正文单图均可见，数量与去重后的 `media_bin_sources` 一致，没有未使用素材混入。
- 全程无离线素材、黑帧、空隙、异常变速、原视频声音或标题位置漂移。

交付时区分“草稿已写入”和“剪映前台已检查”。只有完成上述前台检查后，才能报告横版自然流测试通过。
