# 整书转课程流程

## 1. 读取全书并保存可核对来源

检查目录、正文、附录及页数。文本型文件提取全文，扫描PDF按页OCR；长书分批读完，保存页码与读取进度，不能用目录或检索片段替代完整阅读。去除重复水印、广告等非正文时记录处理范围。区分PDF顺序页与印刷页，引用时固定说明使用哪一种。无法识别的页明确标记，先完成可读部分并说明待补范围。

建立本书独立工作目录，保存原文件引用、提取文本、章节位置与CURRENT_CONTEXT.md，不改原书文件。后续直接复用已核对的提取结果。

## 2. 梳理思想及论证结构

先完成全书思想脉络：书要解决的问题、中心主张、核心概念、理论依据、方法体系、章节递进及结论。保留原术语及作者的逻辑关系，特别留意容易在压缩中丢失的生物学、心理学、技术定义、前提与例外。

区分原书论断、引用研究、类比、假设和个人经历。整理不等于证明书中主张正确；不擅自加科学背书，也不借核验之名无声删除内容。若某项内容只能非操作性概述，在覆盖记录中明确处理，不把它算作已完整操作化。

## 3. 按原书节奏设计课程

以原书章节和思想推进为主线划分模块与课次。每课有独立、可讲清的问题；一个复杂章节可以分多课，重复或短小章节可以合并。保留必要铺垫，不按固定课数硬塞，也不为短课数量机械切碎论证。发生拆并或调整顺序时列出对应章节及理由。

每课标题准确反映内容，保留必要技术名称。用户已确认标题与顺序后，局部调整不自行重做整套课程。

课程大纲列：模块、课序、课名、本课要讲清的问题、关键内容、原书对应章节或页码。不是只列标题。

## 4. 写齐每课骨架并嵌入原书案例

每课至少包含：

- 标题与来源：课序、课名、原书章节及页码。
- 开场问题：从本课具体困惑或矛盾进入，避免视频式效果保证。
- 核心观点：保留原书主张和必要条件，说明本课结论。
- 讲解顺序：按原论证分段写出“讲什么、为什么、如何衔接”；段数随内容，不强制三段。
- 原书精简案例：直接嵌入合适讲解位置，保留情境、关键行动或变化、结果及其说明的观点。原文未写结果就不补。标注真实经历、假设、类型对比、类比或研究叙述的身份，不把类型对比改成咨询故事。
- 收束与衔接：本课要记住的区别或结论，及下一课自然接续的问题。

没有故事案例的章节，用原书概念对比、表格、研究叙述或类比说明，并注明类型；不能编造案例填字段。练习仅在有教学作用时添加，来源外的新练习标明为教学设计。

若用户明确是本书作者，用“我”陈述思想和确属作者的亲历，不能写“作者说”。其他书可用讲师第一人称组织课堂，但保留观点、研究及经历的真实归属，不冒认用户经历。

## 5. 覆盖核对与默认交付

默认形成可继续写稿的一整套材料，可合并为少量清晰文档，不为每个字段单建文件：

1. 全书思想与知识结构：主张、概念、方法、论证递进。
2. 完整课程大纲：模块和全部课次，以及拆并依据。
3. 全部课程骨架：逐课含精简案例、来源及衔接。
4. 概念与案例索引：原术语、简要含义、出处、安排课次；案例出处与使用课次。
5. 覆盖核对：原章节与课程映射，遗漏、合并、重复、无法识别及特殊处理项。

逐章确认实质思想均已安排；核对关键理论、方法、案例没有因压缩而消失；检查课序连续、衔接一致、案例身份正确。不把重复广告、水印或版权页强行安排成课。最终区分“整理完成”与“用户认可”。

整书大纲与骨架在同一授权内继续完成，不逐阶段索要确认。未经用户要求，不自动生成全部逐字稿、PPT或批量调用外部扩写。用户后续指定一课或一批课时，从已确认骨架继续，具体文风依据新的反馈校准。
